

## 问题描述

给定两个字符串 `s`和 `t`，返回 `s`中涵盖 `t`所有字符的最小子串。如果不存在，返回空字符串 `""`。

**要求**：

- 子串必须包含 `t`中所有字符（包括重复字符）。
    
- 保证答案唯一。
    

**示例**：

```
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释：最小窗口子串 "BANC" 包含了 t 中的所有字符 'A'、'B'、'C'。
```

---

## 解题思路（滑动窗口 + 哈希表）

使用双指针维护一个滑动窗口，确保窗口内包含 `t`的所有字符，并不断收缩以找到最小长度。

**核心步骤**：

1. 统计 `t`中每个字符的出现次数（`need`哈希表）。
    
2. 使用 `left`、`right`指针表示窗口边界，`window`哈希表记录当前窗口内字符计数。
    
3. 移动 `right`扩展窗口，直到窗口包含 `t`的所有字符。
    
4. 移动 `left`收缩窗口，同时更新最小子串。
    
5. 重复直到 `right`到达字符串末尾。
    

**优化点**：

- 用 `valid`记录已满足需求的字符种类数，避免每次遍历 `need`检查。

## Java 代码实现

```
import java.util.*;

class Solution {
    public String minWindow(String s, String t) {
        if (s == null || t == null || s.length() == 0 || t.length() == 0) {
            return "";
        }

        // 统计 t 中每个字符的需求数量
        Map<Character, Integer> need = new HashMap<>();
        for (char c : t.toCharArray()) {
            need.put(c, need.getOrDefault(c, 0) + 1);
        }

        // 窗口内字符的计数
        Map<Character, Integer> window = new HashMap<>();
        int left = 0, right = 0;
        int valid = 0;                  // 满足 need 条件的字符种类数
        int start = 0, minLen = Integer.MAX_VALUE;

        while (right < s.length()) {
            char c = s.charAt(right);
            right++;

            // 如果字符在 t 中，更新窗口计数
            if (need.containsKey(c)) {
                window.put(c, window.getOrDefault(c, 0) + 1);
                // 如果当前字符数量恰好满足需求，valid 加一
                if (window.get(c).equals(need.get(c))) {
                    valid++;
                }
            }

            // 当窗口包含所有 t 的字符时，尝试收缩
            while (valid == need.size()) {
                // 更新最小子串
                if (right - left < minLen) {
                    start = left;
                    minLen = right - left;
                }

                // 移除左边界字符
                char d = s.charAt(left);
                left++;
                if (need.containsKey(d)) {
                    // 如果该字符数量不再满足需求，valid 减一
                    if (window.get(d).equals(need.get(d))) {
                        valid--;
                    }
                    window.put(d, window.get(d) - 1);
                }
            }
        }

        return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
    }
}
```

## 算法流程示例

以 `s = "ADOBECODEBANC"`, `t = "ABC"`为例：

|步骤|窗口|状态|
|---|---|---|
|初始|[]|valid = 0|
|扩展|[A]|valid = 1|
|扩展|[A,D,O]|valid = 1|
|扩展|[A,D,O,B]|valid = 2|
|扩展|[A,D,O,B,E,C]|valid = 3（满足条件）|
|收缩|[D,O,B,E,C]|更新最小长度 6|
|继续收缩...最终找到 "BANC"|

---

## 复杂度分析

- **时间复杂度**：O(|s| + |t|)，每个字符最多被访问两次（左右指针各一次）。
    
- **空间复杂度**：O(|s| + |t|)，哈希表存储字符计数。
