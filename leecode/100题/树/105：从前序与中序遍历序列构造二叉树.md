# 一、题目说明


### 题目描述

给定两个整数数组：

- `preorder`：二叉树的前序遍历结果
    
- `inorder`：同一棵树的中序遍历结果
    

要求：

> **构造出这棵二叉树并返回其根节点**

### 示例

```
preorder = [3,9,20,15,7]
inorder  = [9,3,15,20,7]

构造出的二叉树：
      3
     / \
    9  20
      /  \
     15   7
```

# 二、核心解题思路

## 关键性质

|遍历方式|特点|
|---|---|
|前序遍历|✅ 根节点在最前面|
|中序遍历|✅ 根节点左右分别是左右子树|

---

## 解题步骤（递归）

1. **前序数组的第一个元素一定是根节点**
    
2. 在 **中序数组中找到该根节点的位置**
    
3. 根据中序数组：
    
    - 左边部分 → 左子树
        
    - 右边部分 → 右子树
        
    
4. 根据左右子树的节点数量，切分前序数组
    
5. 递归构造左右子树
    

---

## 区间划分公式（重点）

假设：

- 中序根节点索引：`inRoot`
    
- 左子树节点数：`sizeLeft = inRoot - inLeft`
    

### 左子树

|数组|区间|
|---|---|
|前序|`[preLeft + 1, preLeft + sizeLeft]`|
|中序|`[inLeft, inRoot - 1]`|

### 右子树

|数组|区间|
|---|---|
|前序|`[preLeft + sizeLeft + 1, preRight]`|
|中序|`[inRoot + 1, inRight]`|

# 三、整理后的完整 Java 代码 ✅

```
import java.util.HashMap;
import java.util.Map;

/**
 * Definition for a binary tree node.
 */
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}
    TreeNode(int val) {
        this.val = val;
    }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {

    // 用于快速查找中序遍历中根节点的索引
    private Map<Integer, Integer> indexMap;

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        int n = preorder.length;
        indexMap = new HashMap<>();

        // 构建中序遍历值到下标的映射
        for (int i = 0; i < n; i++) {
            indexMap.put(inorder[i], i);
        }

        return build(
                preorder,
                inorder,
                0, n - 1,   // 前序区间
                0, n - 1    // 中序区间
        );
    }

    /**
     * 递归构建二叉树
     */
    private TreeNode build(
            int[] preorder,
            int[] inorder,
            int preLeft,
            int preRight,
            int inLeft,
            int inRight
    ) {
        if (preLeft > preRight) {
            return null;
        }

        // 1. 前序遍历的第一个元素是根节点
        int rootVal = preorder[preLeft];
        TreeNode root = new TreeNode(rootVal);

        // 2. 在中序遍历中找到根节点位置
        int inRoot = indexMap.get(rootVal);
        int leftSize = inRoot - inLeft;

        // 3. 构建左子树
        root.left = build(
                preorder,
                inorder,
                preLeft + 1,
                preLeft + leftSize,
                inLeft,
                inRoot - 1
        );

        // 4. 构建右子树
        root.right = build(
                preorder,
                inorder,
                preLeft + leftSize + 1,
                preRight,
                inRoot + 1,
                inRight
        );

        return root;
    }
}
```

# 四、复杂度分析

|项目|复杂度|
|---|---|
|时间复杂度|**O(n)**​|
|空间复杂度|**O(n)**（哈希表 + 递归栈）|

> 若不使用哈希表，每次在中序数组中线性查找根节点，时间复杂度会退化为 `O(n²)`。
