

## 题目描述

给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

## 示例

**示例 1：**

输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]

输出：6

解释：在这种情况下，可以接 6 个单位的雨水。

**示例 2：**

输入：height = [4,2,0,3,2,5]

输出：9

## 解题思路

对于每个位置，它能接的雨水量取决于它左右两侧最大高度的较小值与该位置高度的差值。

## 双指针解法（最优）

```
class Solution {
    public int trap(int[] height) {
        if (height == null || height.length <= 2) {
            return 0;
        }
        
        int left = 0, right = height.length - 1;
        int leftMax = 0, rightMax = 0;
        int result = 0;
        
        while (left < right) {
            if (height[left] < height[right]) {
                if (height[left] >= leftMax) {
                    leftMax = height[left];
                } else {
                    result += leftMax - height[left];
                }
                left++;
            } else {
                if (height[right] >= rightMax) {
                    rightMax = height[right];
                } else {
                    result += rightMax - height[right];
                }
                right--;
            }
        }
        
        return result;
    }
}
```

## 算法分析

- **时间复杂度**：O(n)，只需要遍历数组一次
    
- **空间复杂度**：O(1)，只使用了常数级别的额外空间
    

## 算法理解

1. 使用两个指针从两端向中间遍历
    
2. 用`leftMax`和`rightMax`记录左右两侧已遍历过的最大高度
    
3. 对于每个位置，能接的水量取决于当前位置高度与左右侧最大高度中较小值的差值
    
4. 因为总是从较矮的一侧开始处理，所以可以确保另一侧的高度足够
    

## 动态规划解法（备用）

```
class Solution {
    public int trap(int[] height) {
        if (height == null || height.length <= 2) {
            return 0;
        }
        
        int n = height.length;
        int[] leftMax = new int[n];
        int[] rightMax = new int[n];
        
        // 计算左侧最大高度
        leftMax[0] = height[0];
        for (int i = 1; i < n; i++) {
            leftMax[i] = Math.max(leftMax[i - 1], height[i]);
        }
        
        // 计算右侧最大高度
        rightMax[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            rightMax[i] = Math.max(rightMax[i + 1], height[i]);
        }
        
        // 计算总雨水量
        int result = 0;
        for (int i = 0; i < n; i++) {
            result += Math.min(leftMax[i], rightMax[i]) - height[i];
        }
        
        return result;
    }
}
```

## 测试用例

```
public class TestTrapRainWater {
    public static void main(String[] args) {
        Solution solution = new Solution();
        
        int[] test1 = {0,1,0,2,1,0,1,3,2,1,2,1};
        System.out.println("Test 1: " + solution.trap(test1)); // 6
        
        int[] test2 = {4,2,0,3,2,5};
        System.out.println("Test 2: " + solution.trap(test2)); // 9
        
        int[] test3 = {};
        System.out.println("Test 3: " + solution.trap(test3)); // 0

    }
}
```
