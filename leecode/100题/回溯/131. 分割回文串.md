## 一、题目描述

给你一个字符串 `s`，请你将 `s`分割成一些子串，使 **每个子串都是回文串**。

返回 `s`**所有可能的分割方案**。

### 示例

```
输入：s = "aab"
输出：
[
  ["a","a","b"],
  ["aa","b"]
]
```

```
输入：s = "a"
输出：
[
  ["a"]
]
```

### 提示

- `1 <= s.length <= 16`
    
- `s`仅由小写英文字母组成
    

---

## 二、解题思路

### 核心思想：**回溯 + 动态规划预处理**

1. **判断回文**
    
    - 暴力判断会超时
        
    - 使用 `dp[i][j]`表示 `s[i..j]`是否为回文
        
    
2. **回溯枚举分割方式**
    
    - 从位置 `start`开始
        
    - 枚举 `end`，如果 `s[start..end]`是回文，就加入路径
        
    - 递归处理 `end + 1`
        
    - 回溯撤销选择

## 三、Java 实现代码（✅ 推荐写法）

```
import java.util.*;

class Solution {

    public List<List<String>> partition(String s) {
        int n = s.length();

        // dp[i][j] 表示 s[i..j] 是否是回文
        boolean[][] dp = new boolean[n][n];

        // 单个字符一定是回文
        for (int i = 0; i < n; i++) {
            dp[i][i] = true;
        }

        // 枚举子串长度
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = (len == 2) ? true : dp[i + 1][j - 1];
                } else {
                    dp[i][j] = false;
                }
            }
        }

        List<List<String>> res = new ArrayList<>();
        backtrack(s, 0, new ArrayList<>(), res, dp);
        return res;
    }

    private void backtrack(String s, int start, List<String> path,
                           List<List<String>> res, boolean[][] dp) {
        if (start == s.length()) {
            res.add(new ArrayList<>(path));
            return;
        }

        for (int end = start; end < s.length(); end++) {
            if (dp[start][end]) {
                path.add(s.substring(start, end + 1));
                backtrack(s, end + 1, path, res, dp);
                path.remove(path.size() - 1);
            }
        }
    }
}
```

## 五、面试要点总结（⭐常考）

- ✅ 回溯模板：`选择 → 递归 → 撤销`
    
- ✅ 回文判断一定要 **预处理 DP**
    
- ✅ 注意 `substring(start, end + 1)`
    
- ✅ 结果要 `new ArrayList<>(path)`，否则会被覆盖
