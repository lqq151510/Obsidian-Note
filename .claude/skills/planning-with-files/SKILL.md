# planning-with-files

## Goal
Create actionable plans directly mapped to repository files.

## Workflow
1. Discover relevant files and dependencies.
2. Break work into minimal file-level edits.
3. Identify risks, tests, and rollback points.
4. Execute incrementally and verify after each step.

## Output format
- File map
- Step-by-step plan
- Validation commands
