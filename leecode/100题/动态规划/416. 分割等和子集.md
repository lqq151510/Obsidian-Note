## 一、题目描述

**题目：416. 分割等和子集（Partition Equal Subset Sum）**​

**难度：中等**

给你一个 **只包含正整数**​ 的 **非空**​ 数组 `nums`。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

---

## 二、示例

|输入|输出|说明|
|---|---|---|
|`nums = [1,5,11,5]`|`true`|可以分割成 `[1,5,5]`和 `[11]`|
|`nums = [1,2,3,5]`|`false`|总和为 11，无法平分|
|`nums = [2,2,3,3]`|`true`|可以分割成 `[2,2,3]`和 `[3]`|

---

## 三、解题思路（0-1 背包问题 ✅）

### 核心转化

- 若数组总和 `sum`为奇数，直接返回 `false`
    
- 若 `sum`为偶数，则问题转化为：**是否存在一个子集，其和为 `sum/2`**
    

### 动态规划定义

- `dp[j]`：表示是否存在和为 `j`的子集
    

### 状态转移

对于每个元素 `num`，从后往前遍历 `j`（`j`从 `sum/2`到 `num`）：

- `dp[j] = dp[j] || dp[j - num]`
    
    - 含义：不选当前元素时 `dp[j]`为真，或选当前元素时 `dp[j-num]`为真
        
    

### 初始化

- `dp[0] = true`（空集的和为 0）
    

---

## 四、Java 代码实现（推荐 ✅）

```
class Solution {
    public boolean canPartition(int[] nums) {
        int sum = 0;
        for (int num : nums) {
            sum += num;
        }
        
        // 总和为奇数，无法平分
        if (sum % 2 != 0) {
            return false;
        }
        
        int target = sum / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true; // 空集的和为0
        
        // 遍历每个元素
        for (int num : nums) {
            // 从后往前遍历，避免重复使用元素
            for (int j = target; j >= num; j--) {
                dp[j] = dp[j] || dp[j - num];
            }
        }
        
        return dp[target];
    }
}
```

---

## 五、复杂度分析

|指标|结果|
|---|---|
|时间复杂度|**O(n × target)**（n 为数组长度，target 为总和的一半）|
|空间复杂度|**O(target)**（一维数组）|

---

## 六、执行过程示例

以 `nums = [1,5,11,5]`为例：

1. 总和 `sum = 22`，`target = 11`
    
2. 初始化 `dp[0] = true`
    
3. 处理 `num=1`：`dp[1] = true`
    
4. 处理 `num=5`：`dp[5]=true`, `dp[6]=true`
    
5. 处理 `num=11`：`dp[11] = true`（直接命中目标）
    
6. 返回 `true`
    

---

## 七、面试要点 ✅

- ✅ 先判断总和是否为偶数是关键剪枝
    
- ✅ 本质是 **0-1 背包问题**（每个元素只能用一次）
    
- ✅ 使用 **一维数组 + 倒序遍历**​ 避免重复使用元素
    
- ✅ 初始化 `dp[0] = true`是逻辑基础
    

---

## 八、常见错误 ❌

|错误|说明|
|---|---|
|未判断总和为奇数|导致无效计算|
|正序遍历 `j`|会重复使用同一元素（变成完全背包）|
|忽略空数组或非正整数|题目保证非空且为正整数|
|未处理大数组|当 `target`很大时可能超时（但本题通常可接受）|
