
**题目描述**：给定两个字符串 `s`和 `p`，找到 `s`中所有 `p`的 **异位词**​ 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

**异位词定义**：由相同字符组成但排列顺序不同的字符串（如 `"abc"`和 `"cba"`互为异位词）。

#### 示例

|输入|输出|说明|
|---|---|---|
|`s = "cbaebabacd", p = "abc"`|`[0,6]`|起始索引 `0`对应子串 `"cba"`，`6`对应子串 `"bac"`，均为 `p`的异位词|
|`s = "abab", p = "ab"`|`[0,1,2]`|子串 `"ab"`、`"ba"`、`"ab"`均为 `p`的异位词|

---

### 代码实现（Java）

```
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<>();
        int sLen = s.length(), pLen = p.length();
        if (sLen < pLen) return result; // 边界条件：s长度小于p，无异位词

        // 计数数组：统计字符频率（仅处理小写字母，故大小为26）
        int[] pCount = new int[26]; // p中每个字符的频率
        int[] sCount = new int[26]; // 当前窗口中每个字符的频率

        // 1. 统计p的字符频率
        for (char c : p.toCharArray()) {
            pCount[c - 'a']++;
        }

        // 2. 滑动窗口遍历s（固定窗口大小为pLen）
        for (int i = 0; i < sLen; i++) {
            // 右侧字符进入窗口
            sCount[s.charAt(i) - 'a']++;

            // 窗口超出p的长度时，左侧字符移出窗口（保持窗口大小=pLen）
            if (i >= pLen) {
                char leftChar = s.charAt(i - pLen);
                sCount[leftChar - 'a']--;
            }

            // 窗口大小等于pLen时，比较频率数组
            if (i >= pLen - 1) {
                if (Arrays.equals(pCount, sCount)) {
                    result.add(i - pLen + 1); // 起始索引=当前位置-pLen+1
                }
            }
        }
        return result;
    }
}
```

---

### 关键思路说明

1. **滑动窗口+计数数组**：
    
    用固定大小的滑动窗口（大小等于 `p`的长度）遍历 `s`，维护窗口内字符的频率数组 `sCount`，并与 `p`的频率数组 `pCount`比较。
    
2. **窗口调整逻辑**：
    
    - 每次循环将右侧字符加入窗口；
        
    - 当窗口长度超过 `p`时，移除左侧字符（保证窗口大小始终为 `pLen`）；
        
    - 窗口大小等于 `pLen`时，若两数组相等，则当前窗口是 `p`的异位词。
        
    
3. **复杂度分析**：
    
    - **时间复杂度**：`O(n)`（`n`为 `s`的长度，每个字符仅被处理一次，数组比较为常数时间）；
        
    - **空间复杂度**：`O(26)`（计数数组大小固定为26，仅处理小写字母）。
