## 一、题目描述

**题目：152. 乘积最大子数组（Maximum Product Subarray）**​

**难度：中等**

给你一个整数数组 `nums`，请你找出数组中乘积最大的**非空连续子数组**（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

**注意：**

- 测试用例的答案是一个 **32 位整数**
    
- 一个只包含一个元素的数组的乘积就是这个元素的值
    

---

## 二、示例

|输入|输出|说明|
|---|---|---|
|`nums = [2,3,-2,4]`|`6`|子数组 `[2,3]`的乘积为 `6`|
|`nums = [-2,0,-1]`|`0`|子数组 `[-2,0]`或 `[0]`的乘积为 `0`|
|`nums = [-2,3,-4]`|`24`|子数组 `[-2,3,-4]`的乘积为 `24`|

---

## 三、解题思路（动态规划 + 正负切换 ✅）

### 核心难点

乘法与加法不同：**负数 × 负数 = 正数**，因此不能像“最大子数组和”那样只维护一个最大值。

### 关键思想

在遍历数组时，同时维护：

- `max`：以当前元素结尾的连续子数组的**最大乘积**
    
- `min`：以当前元素结尾的连续子数组的**最小乘积**
    

### 为什么需要 `min`？

- 当遇到负数时，**最小乘积 × 负数**​ 可能变成最大乘积
    
- 因此必须同时记录最小乘积
    

### 负数处理逻辑（关键 ✅）

当 `nums[i] < 0`时：

- 原来的 `max`会变成最小
    
- 原来的 `min`会变成最大
    
    👉 **交换 `max`和 `min`**
    

### 状态更新

```
max = max(num, max * num);
min = min(num, min * num);
```

---

## 四、Java 代码实现（你给出的版本 ✅）

```
class Solution {
    public int maxProduct(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }

        int max = nums[0];   // 以当前元素结尾的最大乘积
        int min = nums[0];   // 以当前元素结尾的最小乘积
        int result = nums[0]; // 全局最大乘积

        for (int i = 1; i < nums.length; i++) {
            int num = nums[i];

            // 关键：遇到负数时，最大和最小会发生反转
            if (num < 0) {
                int temp = max;
                max = min;
                min = temp;
            }

            // 更新以当前元素结尾的最大和最小乘积
            max = Math.max(num, max * num);
            min = Math.min(num, min * num);

            // 更新全局最大值
            result = Math.max(result, max);
        }

        return result;
    }
}
```

---

## 五、执行过程示例

以 `nums = [2,3,-2,4]`为例：

|i|num|max（交换前）|min（交换前）|max（更新后）|min（更新后）|result|
|---|---|---|---|---|---|---|
|0|2|2|2|2|2|2|
|1|3|3|3|6|3|6|
|2|-2|6|3|-2|-12|6|
|3|4|-2|-12|4|-48|6|

✅ 最终结果为 `6`

## 七、面试要点 ✅

- ✅ **必须同时维护最大值和最小值**
    
- ✅ 遇到负数时 **交换 `max`和 `min`**
    
- ✅ 每次更新都要与当前元素自身比较（防止被 0 或单个负数拖累）
    
- ✅ 初始化为 `nums[0]`，不能使用 `0`
    
- ✅ 这是 **最大子数组和的乘法版本**
    

---

## 八、常见错误 ❌

|错误|说明|
|---|---|
|只维护一个最大值|会漏掉负数翻转的情况|
|初始化为 0|会导致正确结果被覆盖|
|忽略单个元素|数组只有一个元素时，乘积就是该元素|
|忘记交换 max/min|负数场景会出错|
