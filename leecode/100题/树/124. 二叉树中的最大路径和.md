## 一、题目描述

**题目：124. 二叉树中的最大路径和（Binary Tree Maximum Path Sum）**​

**难度：困难**

二叉树中的 **路径**​ 被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中 **至多出现一次**。该路径 **至少包含一个节点**，且不一定经过根节点。

**路径和**​ 是路径中各节点值的总和。

给你一个二叉树的根节点 `root`，返回其 **最大路径和**。

---

## 二、示例

|输入|输出|解释|
|---|---|---|
|`[1,2,3]`|`6`|最优路径：`2 → 1 → 3`，和为 `6`|
|`[-10,9,20,null,null,15,7]`|`42`|最优路径：`15 → 20 → 7`，和为 `42`|
|`[1]`|`1`|只有根节点|

---

## 三、解题思路（树形 DP ✅）

### 核心思想

对于任意一个节点，最大路径和可能有两种情况：

1. **以该节点为最高点**：路径从左子树上来 → 经过该节点 → 到右子树下去
    
2. **路径完全位于左子树或右子树中**
    

### 递归设计

- **返回值**：以当前节点为起点的 **单边最大路径和**（只能选左或右一条分支，用于给父节点汇报）
    
- **在递归过程中**：计算 **经过当前节点的最大路径和**，并更新全局最大值
    

### 关键公式

```
当前节点贡献 = 节点值 + max(左子树贡献, 右子树贡献, 0)
当前路径和 = 节点值 + max(左子树贡献, 0) + max(右子树贡献, 0)
```

## 四、Java 代码实现（推荐 ✅）

```
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    // 全局最大路径和
    private int maxSum = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        dfs(root);
        return maxSum;
    }

    /**
     * 返回以当前节点为起点的单边最大路径和
     * （只能向上传递一条分支）
     */
    private int dfs(TreeNode node) {
        if (node == null) {
            return 0;
        }

        // 左子树的最大贡献（若为负则取 0）
        int leftGain = Math.max(dfs(node.left), 0);
        // 右子树的最大贡献（若为负则取 0）
        int rightGain = Math.max(dfs(node.right), 0);

        // 以当前节点为最高点的最大路径和
        int currentPathSum = node.val + leftGain + rightGain;
        maxSum = Math.max(maxSum, currentPathSum);

        // 返回给父节点：只能选一条分支
        return node.val + Math.max(leftGain, rightGain);
    }
}
```

## 五、复杂度分析

|指标|结果|
|---|---|
|时间复杂度|**O(n)**（每个节点访问一次）|
|空间复杂度|**O(h)**（递归栈深度，h 为树高）|

## 六、执行过程示意

以 `[-10,9,20,null,null,15,7]`为例：

```
-10
      /   \
     9     20
          /  \
         15   7
```

- 节点 `15`：贡献 = `15`
    
- 节点 `7`：贡献 = `7`
    
- 节点 `20`：路径和 = `20 + 15 + 7 = 42`（更新全局最大值）
    
- 节点 `9`：贡献 = `9`
    
- 节点 `-10`：路径和 = `-10 + 9 + 35 = 34`（小于 `42`）
    

✅ 最终最大路径和为 **42**

## 七、面试要点 ✅

- ✅ 使用 **后序遍历（DFS）**
    
- ✅ 负数贡献直接舍弃（取 `0`）
    
- ✅ 全局变量记录最大值
    
- ✅ 返回给父节点时 **只能选一条分支**
    
- ✅ 每个节点只计算一次，不重复
    

---

## 八、常见错误 ❌

|错误|说明|
|---|---|
|返回左右子树之和|会导致路径分叉，违反题目要求|
|忽略负数节点|可能丢失全为负数的情况|
|未处理空节点|递归边界错误|
