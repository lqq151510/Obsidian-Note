## 一、题目描述

**题目：295. 数据流的中位数（Find Median from Data Stream）**​

**难度：困难**

中位数是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

例如：

- `arr = [2,3,4]`的中位数是 `3`
    
- `arr = [2,3]`的中位数是 `(2 + 3) / 2 = 2.5`
    

实现 `MedianFinder`类：

- `MedianFinder()`初始化 `MedianFinder`对象
    
- `void addNum(int num)`将数据流中的整数 `num`添加到数据结构中
    
- `double findMedian()`返回目前所有元素的中位数
    

---

## 二、示例

|操作|结果|
|---|---|
|`addNum(1)`|-|
|`addNum(2)`|-|
|`findMedian()`|`1.5`|
|`addNum(3)`|-|
|`findMedian()`|`2.0`|

## 三、解题思路（双堆法 ✅）

### 核心思想

使用 **两个堆**​ 维护数据流的两部分：

- **大顶堆（maxHeap）**：存储较小的一半元素，堆顶是这部分的最大值
    
- **小顶堆（minHeap）**：存储较大的一半元素，堆顶是这部分的最小值
    

### 关键规则

1. 两个堆的大小满足：
    
    - 大顶堆的大小 ≥ 小顶堆的大小
        
    - 大顶堆的大小 - 小顶堆的大小 ≤ 1
        
    
2. 所有大顶堆中的元素 ≤ 所有小顶堆中的元素
    

### 中位数计算

- 若总元素个数为奇数：中位数是 **大顶堆的堆顶**
    
- 若总元素个数为偶数：中位数是 **两个堆顶的平均值**

## 四、Java 代码实现（推荐 ✅）

```
import java.util.Collections;
import java.util.PriorityQueue;

class MedianFinder {
    // 大顶堆：存储较小的一半元素
    private PriorityQueue<Integer> maxHeap;
    // 小顶堆：存储较大的一半元素
    private PriorityQueue<Integer> minHeap;

    /** 初始化数据结构 */
    public MedianFinder() {
        maxHeap = new PriorityQueue<>(Collections.reverseOrder()); // 大顶堆
        minHeap = new PriorityQueue<>(); // 小顶堆
    }

    /** 向数据流中添加一个整数 */
    public void addNum(int num) {
        // 1. 根据当前堆的状态决定插入哪个堆
        if (maxHeap.isEmpty() || num <= maxHeap.peek()) {
            maxHeap.offer(num);
        } else {
            minHeap.offer(num);
        }

        // 2. 调整堆的大小，保持平衡
        // 如果大顶堆比小顶堆多 2 个元素，将大顶堆的堆顶移到小顶堆
        if (maxHeap.size() > minHeap.size() + 1) {
            minHeap.offer(maxHeap.poll());
        }
        // 如果小顶堆比大顶堆多 1 个元素，将小顶堆的堆顶移到大顶堆
        else if (minHeap.size() > maxHeap.size()) {
            maxHeap.offer(minHeap.poll());
        }
    }

    /** 返回当前数据流的中位数 */
    public double findMedian() {
        // 奇数个元素：中位数是大顶堆的堆顶
        if (maxHeap.size() > minHeap.size()) {
            return maxHeap.peek();
        }
        // 偶数个元素：中位数是两个堆顶的平均值
        else {
            return (maxHeap.peek() + minHeap.peek()) / 2.0;
        }
    }
}
```

## 六、执行过程示例

以数据流 `[2, 3, 4]`为例：

1. `addNum(2)`：
    
    - 插入大顶堆 → `maxHeap = [2]`, `minHeap = []`
        
    
2. `addNum(3)`：
    
    - 3 > 2 → 插入小顶堆 → `minHeap = [3]`
        
    - 调整：大小相等 → 中位数 `(2+3)/2 = 2.5`
        
    
3. `addNum(4)`：
    
    - 4 > 2 → 插入小顶堆 → `minHeap = [3,4]`
        
    - 调整：`minHeap.size() > maxHeap.size()`→ 将 `3`移到大顶堆
        
    - 结果：`maxHeap = [3,2]`, `minHeap = [4]`→ 中位数 `3`

## 七、面试要点 ✅

- ✅ 使用 **双堆**​ 是最高效的解法
    
- ✅ 大顶堆用 `Collections.reverseOrder()`实现
    
- ✅ 插入时先判断归属，再调整堆的大小平衡
    
- ✅ `findMedian()`直接取堆顶，无需额外计算
    
- ✅ 这是面试高频题，务必手写熟练

## 八、常见错误 ❌

|错误|说明|
|---|---|
|只用一个堆|无法高效获取中位数|
|堆大小不平衡|导致中位数计算错误|
|未处理空堆情况|可能引发空指针异常|
