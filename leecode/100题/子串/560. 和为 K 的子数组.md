

## 问题描述

给定一个整数数组 `nums`和一个整数 `k`，请统计并返回该数组中**和为 `k`的子数组的个数**。

子数组是数组中元素的**连续非空序列**。

**示例：**

```
输入：nums = [1,1,1], k = 2
输出：2
解释：子数组 [1,1] 和 [1,1] 的和都为 2。
```

## 解决方案（前缀和 + 哈希表）

```
class Solution {
    public int subarraySum(int[] nums, int k) {
        int count = 0;          // 记录满足条件的子数组个数
        int pre = 0;            // 当前前缀和

        Map<Integer, Integer> map = new HashMap<>();
        map.put(0, 1);          // 初始化：前缀和为 0 出现 1 次

        for (int num : nums) {
            pre += num;         // 更新前缀和

            // 如果之前存在前缀和等于 pre - k，则当前区间和为 k
            if (map.containsKey(pre - k)) {
                count += map.get(pre - k);
            }

            // 将当前前缀和存入哈希表，计数加一
            map.put(pre, map.getOrDefault(pre, 0) + 1);
        }
        return count;
    }
}
```

## 算法解析

- **核心思想**：利用前缀和快速计算任意子数组的和。
    
    设 `pre[i]`为 `[0..i]`的元素和，则子数组 `[j+1..i]`的和为 `pre[i] - pre[j]`。
    
    若 `pre[i] - pre[j] = k`，则 `pre[j] = pre[i] - k`。
    
    因此，遍历数组时，只需查找之前出现过多少次 `pre - k`即可。
    
- **哈希表作用**：记录每个前缀和出现的次数，实现 O(1) 查询。
    
- **初始化 `map.put(0, 1)`**：处理从第一个元素开始的子数组（此时前缀和本身等于 k）。
    

## 复杂度分析

- **时间复杂度**：O(n)，仅一次遍历。
    
- **空间复杂度**：O(n)，哈希表最多存储 n 个不同的前缀和。
    

此解法高效且简洁，是经典的前缀和应用场景。
