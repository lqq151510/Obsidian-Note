# claude-obsidian

## Goal
Improve Obsidian notes for retrieval and consistency.

## Workflow
1. Normalize titles and headings.
2. Add/repair backlinks and tag taxonomy.
3. Split oversized notes and add index pages when needed.
4. Preserve original meaning while improving structure.

## Output format
- Updated note paths
- Added links/tags
- Suggested follow-up notes
