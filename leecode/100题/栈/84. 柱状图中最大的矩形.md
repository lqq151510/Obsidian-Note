## 题目描述

给定 n 个非负整数，表示柱状图中各柱子的高度。每个柱子宽度为 1，求柱状图中能勾勒出的最大矩形面积。

**示例 1：**

https://assets.leetcode.com/uploads/2021/01/04/histogram.jpg

```
输入：heights = [2,1,5,6,2,3]
输出：10
解释：最大的矩形为图中红色区域，面积为 10。
```

**示例 2：**

https://assets.leetcode.com/uploads/2021/01/04/histogram-1.jpg

```
输入：heights = [2,4]
输出：4
```

## 解题思路：单调栈

暴力法需要枚举每个柱子作为矩形高度，并向左右扩展找到边界，时间复杂度为 O(n²)。利用**单调递增栈**可以将时间复杂度优化到 O(n)。

**核心思想**：对每个柱子，找到其左右两侧**第一个比它矮的柱子**，这两个柱子之间的宽度即为该柱子能构成矩形的最大宽度。

- 维护一个栈，栈中存储柱子的**索引**，并保证这些索引对应的柱子高度是**单调递增**的。
    
- 当遇到一个比栈顶柱子矮的柱子时，说明栈顶柱子的**右边界**已确定（当前柱子），左边界为栈顶的下一个元素（栈中相邻的索引）。此时可以计算以栈顶柱子为高度的矩形面积。
    

为简化边界处理，在数组首尾各插入一个高度为 0 的“哨兵”柱子。

## 代码实现

```
import java.util.Stack;

class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length;
        // 构造带哨兵的数组，首尾各加一个0
        int[] newHeights = new int[n + 2];
        newHeights[0] = 0;
        newHeights[n + 1] = 0;
        for (int i = 1; i <= n; i++) {
            newHeights[i] = heights[i - 1];
        }
        
        Stack<Integer> stack = new Stack<>();
        stack.push(0);  // 先压入哨兵索引0
        int maxArea = 0;
        
        for (int i = 1; i < newHeights.length; i++) {
            // 当前高度小于栈顶高度时，计算栈顶柱子的矩形面积
            while (newHeights[i] < newHeights[stack.peek()]) {
                int height = newHeights[stack.pop()];  // 弹出栈顶，得到高度
                int width = i - stack.peek() - 1;     // 宽度 = 右边界i - 左边界(新栈顶) - 1
                maxArea = Math.max(maxArea, height * width);
            }
            stack.push(i);
        }
        return maxArea;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，每个柱子最多入栈和出栈一次，共 2n 次操作。
    
- **空间复杂度**：O(n)，额外使用了栈和哨兵数组。
