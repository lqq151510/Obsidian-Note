## 📌 问题描述

- **题目**：33. 搜索旋转排序数组（Search in Rotated Sorted Array）
    
- **难度**：中等
    
- **要求**：时间复杂度 **O(log n)**
    
- **说明**：
    
    - 给定数组 `nums`原本按升序排列，但在某个未知下标 `k`处进行了旋转。
        
    - 数组元素 **互不相同**。
        
    - 若 `target`存在于数组中，返回其下标；否则返回 `-1`。
        
    

---

## ✅ 你的原始代码

```
class Solution {
    public int search(int[] nums, int target) {
        if (nums == null || nums.length == 0) {
            return -1;
        }
        int left = 0;
        int right = nums.length - 1;

        while (left <= right) {
            int mid = (right + left) / 2; // ⚠️ 潜在溢出
            if (target == nums[mid]) {
                return mid;
            }

            if (nums[left] <= nums[mid]) {
                if (target >= nums[left] && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else {
                if (target <= nums[right] && target > nums[mid]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }
        return -1;
    }
}
```

---

## 🔧 优化后的代码（推荐）

主要改动：

1. 使用 `left + (right - left) / 2`防止整数溢出。
    
2. 添加清晰注释，便于理解。
    

```
class Solution {
    public int search(int[] nums, int target) {
        if (nums == null || nums.length == 0) {
            return -1;
        }

        int left = 0;
        int right = nums.length - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2; // 防止溢出

            if (nums[mid] == target) {
                return mid;
            }

            // 判断左半部分是否有序
            if (nums[left] <= nums[mid]) {
                // target 落在左半部分的有序区间内
                if (target >= nums[left] && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else { // 右半部分有序
                // target 落在右半部分的有序区间内
                if (target > nums[mid] && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }
        return -1;
    }
}
```

## 🧪 示例

|输入|输出|
|---|---|
|`nums = [4,5,6,7,0,1,2]`, `target = 0`|`4`|
|`nums = [4,5,6,7,0,1,2]`, `target = 3`|`-1`|
|`nums = [1]`, `target = 0`|`-1`|

---

## 💡 核心思想

- 每次二分时，**至少有一半是有序的**。
    
- 判断 `target`是否在有序的那一半中，从而缩小搜索区间。
