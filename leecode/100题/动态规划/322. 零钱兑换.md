## 一、题目描述

**题目：322. 零钱兑换（Coin Change）**

**难度：中等**

给你一个整数数组 `coins`，表示不同面额的硬币；以及一个整数 `amount`，表示总金额。

计算并返回可以凑成总金额所需的 **最少的硬币个数**。如果没有任何一种硬币组合能组成总金额，返回 `-1`。

你可以认为每种硬币的数量是无限的。

---

## 二、示例

|输入|输出|说明|
|---|---|---|
|`coins = [1,2,5], amount = 11`|`3`|`11 = 5 + 5 + 1`，共 3 枚硬币|
|`coins = [2], amount = 3`|`-1`|无法凑成 3|
|`coins = [1], amount = 0`|`0`|总金额为 0，不需要硬币|

---

## 三、解题思路（动态规划 ✅）

### 核心思想

这是一个典型的 **完全背包问题**，使用动态规划求解最优解。

### 状态定义

- `dp[i]`：凑成金额 `i`所需的最少硬币个数
    

### 状态转移方程

对于每个金额 `i`，遍历所有硬币面额 `coin`：

- 如果 `coin <= i`，则 `dp[i] = min(dp[i], dp[i - coin] + 1)`
    
    - 含义：使用一枚面额为 `coin`的硬币，加上凑成 `i - coin`的最少硬币数
        
    

### 初始化

- `dp[0] = 0`（凑 0 元需要 0 枚硬币）
    
- 其他 `dp[i]`初始化为一个极大值（如 `amount + 1`），表示暂时无法凑成
    

### 最终结果

- 若 `dp[amount] > amount`，说明无法凑成，返回 `-1`
    
- 否则返回 `dp[amount]`
    

---

## 四、Java 代码实现（推荐 ✅）

```
import java.util.Arrays;

class Solution {
    public int coinChange(int[] coins, int amount) {
        // 特殊情况处理
        if (amount == 0) return 0;
        if (coins == null || coins.length == 0) return -1;

        // dp[i] 表示凑成金额 i 所需的最少硬币数
        int[] dp = new int[amount + 1];
        // 初始化为一个不可能的大值（最多需要 amount 枚 1 元硬币）
        Arrays.fill(dp, amount + 1);
        dp[0] = 0; // 凑 0 元需要 0 枚硬币

        // 遍历所有金额（从 1 到 amount）
        for (int i = 1; i <= amount; i++) {
            // 遍历所有硬币面额
            for (int coin : coins) {
                if (coin <= i) {
                    // 状态转移：使用当前硬币，更新最少硬币数
                    dp[i] = Math.min(dp[i], dp[i - coin] + 1);
                }
            }
        }

        // 判断是否无法凑成（若 dp[amount] 仍为初始值，说明无法凑成）
        return dp[amount] > amount ? -1 : dp[amount];
    }
}
```

## 五、复杂度分析

|指标|结果|
|---|---|
|时间复杂度|**O(amount × n)**（n 为硬币种类数）|
|空间复杂度|**O(amount)**​|

## 六、执行过程示例

以 `coins = [1,2,5], amount = 11`为例：

- `dp[0] = 0`
    
- `dp[1] = dp[0] + 1 = 1`
    
- `dp[2] = min(dp[1]+1=2, dp[0]+1=1) = 1`
    
- `dp[5] = dp[0] + 1 = 1`
    
- `dp[11] = min(dp[10]+1, dp[9]+1, dp[6]+1) = 3`（例如 `5+5+1`）
    

---

## 七、面试要点 ✅

- ✅ 明确 **完全背包问题**​ 的动态规划思路
    
- ✅ 初始化 `dp`数组时避免溢出（使用 `amount + 1`）
    
- ✅ 注意边界条件：`amount == 0`、`coins`为空
    
- ✅ **不能用贪心算法**（反例：`coins=[9,6,5,1], amount=11`，贪心得到 `9+1+1=3`，最优解为 `5+6=2`）
    

---

## 八、常见错误 ❌

|错误|说明|
|---|---|
|使用贪心算法|可能导致非最优解|
|未处理 `amount == 0`|应直接返回 0|
|初始化 `dp`为 `Integer.MAX_VALUE`|可能导致加法溢出|
|忽略硬币面额大于 `amount`的情况|需在循环中判断 `coin <= i`|
