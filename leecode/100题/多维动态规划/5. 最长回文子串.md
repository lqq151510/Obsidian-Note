## 一、题目描述

**题目：5. 最长回文子串（Longest Palindromic Substring）**​

**难度：中等**

给你一个字符串 `s`，找到 `s`中最长的 **回文子串**。

**回文串**：正读和反读都一样的字符串（例如 `"aba"`、`"bb"`）。

---

## 二、示例

|输入|输出|说明|
|---|---|---|
|`"babad"`|`"bab"`或 `"aba"`|最长回文子串不唯一|
|`"cbbd"`|`"bb"`|偶数长度回文|
|`"a"`|`"a"`|单个字符本身就是回文|
|`"ac"`|`"a"`或 `"c"`|最短回文|

---

## 三、解题思路（中心扩展法 ✅）

### 核心思想

回文串有两种形式：

1. **奇数长度**：中心是单个字符（如 `"aba"`，中心是 `'b'`）
    
2. **偶数长度**：中心是两个相同字符（如 `"abba"`，中心是 `'bb'`）
    

遍历字符串中的每个字符，分别以该字符为中心向两边扩展，记录最长回文串。

### 算法步骤

1. 若字符串为空或长度为 1，直接返回原字符串
    
2. 遍历每个字符 `i`：
    
    - 以 `i`为中心扩展（奇数长度）
        
    - 以 `i`和 `i+1`为中心扩展（偶数长度）
        
    
3. 比较所有扩展结果，记录最长回文串的起始位置和长度
    

---

## 四、Java 代码实现（推荐 ✅）

```
class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 2) {
            return s;
        }
        
        int start = 0; // 最长回文串起始索引
        int maxLen = 1; // 最长回文串长度
        
        for (int i = 0; i < s.length(); i++) {
            // 奇数长度回文（中心是单个字符）
            int len1 = expandAroundCenter(s, i, i);
            // 偶数长度回文（中心是两个字符）
            int len2 = expandAroundCenter(s, i, i + 1);
            
            int len = Math.max(len1, len2);
            if (len > maxLen) {
                maxLen = len;
                start = i - (len - 1) / 2; // 计算起始索引
            }
        }
        
        return s.substring(start, start + maxLen);
    }
    
    /**
     * 从中心向两边扩展，返回回文串长度
     * @param s 原字符串
     * @param left 左边界
     * @param right 右边界
     * @return 回文串长度
     */
    private int expandAroundCenter(String s, int left, int right) {
        while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        // 注意：退出循环时，left和right已经越界，实际长度是 right - left - 1
        return right - left - 1;
    }
}
```

## 五、复杂度分析

|指标|结果|
|---|---|
|时间复杂度|**O(n²)**（每个字符扩展 O(n)）|
|空间复杂度|**O(1)**（常数空间）|

## 六、执行过程示例

以 `s = "babad"`为例：

|i|奇数扩展（中心 i）|偶数扩展（中心 i,i+1）|最长长度|
|---|---|---|---|
|0|`"b"`（长度 1）|`"ba"`（非回文）|1|
|1|`"aba"`（长度 3）|`"bab"`（长度 3）|3|
|2|`"bab"`（长度 3）|`"ada"`（长度 3）|3|
|3|`"a"`（长度 1）|`"ad"`（非回文）|3|
|4|`"d"`（长度 1）|-|3|

✅ 最长回文子串为 `"bab"`或 `"aba"`

---

## 七、面试要点 ✅

- ✅ **中心扩展法**​ 是最常用且易实现的解法
    
- ✅ 必须同时处理奇数和偶数长度回文
    
- ✅ 注意边界条件（空字符串、单字符）
    
- ✅ 计算起始索引的公式：`start = i - (len - 1) / 2`
    

---

## 八、常见错误 ❌

|错误|说明|
|---|---|
|忽略偶数长度回文|会漏掉 `"bb"`这类情况|
|扩展时越界|未检查 `left >= 0`和 `right < s.length()`|
|起始索引计算错误|导致截取的子串不正确|

---

## 九、进阶解法（Manacher 算法）

Manacher 算法可在 **O(n)**​ 时间内解决问题，但实现复杂，面试中通常不要求掌握。其核心思想是利用回文串的对称性减少重复计算。
