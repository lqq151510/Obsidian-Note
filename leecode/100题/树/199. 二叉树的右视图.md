
## 题目描述

给定一个二叉树的 **根节点 `root`**，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

## 示例

```
输入: [1,2,3,null,5,null,4]
输出: [1,3,4]
解释:
   1            <---
 /   \
2     3         <---
 \     \
  5     4       <---
```

## 解题思路

### 方法一：广度优先搜索（BFS）

- 按层遍历二叉树，每层最后一个节点即为该层最右侧可见节点。
    
- 使用队列进行层次遍历，记录每层节点数，将每层的最后一个节点加入结果列表。
    

### 方法二：深度优先搜索（DFS）

- 优先遍历右子树，再遍历左子树。
    
- 当首次到达某一深度时，该节点即为该层最右侧节点（因为右子树先被访问）。
    
- 使用递归，记录当前深度，若结果列表大小等于深度，则添加当前节点值。
    

## 代码实现

### BFS 解法

```
import java.util.*;

class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size(); // 当前层的节点数量
            
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                
                // 如果是当前层的最后一个节点，加入结果集
                if (i == levelSize - 1) {
                    res.add(node.val);
                }
                
                // 将下一层节点加入队列
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
        }
        return res;
    }
}
```

### DFS 解法

```
import java.util.*;

class Solution {
    List<Integer> res = new ArrayList<>();

    public List<Integer> rightSideView(TreeNode root) {
        dfs(root, 0);
        return res;
    }

    private void dfs(TreeNode node, int depth) {
        if (node == null) return;

        // 如果当前深度等于结果集的大小，说明这是该层第一个被访问的节点
        // 由于我们先递归右子树，所以这个节点一定是该层最右边的
        if (depth == res.size()) {
            res.add(node.val);
        }

        // 重点：先往右走，再往左走
        dfs(node.right, depth + 1);
        dfs(node.left, depth + 1);
    }
}
```

## 复杂度分析

|方法|时间复杂度|空间复杂度|
|---|---|---|
|BFS|O(n)|O(n)|
|DFS|O(n)|O(n)（最坏情况递归栈深度）|

两种方法均可高效解决问题，BFS 更直观，DFS 代码更简洁。
