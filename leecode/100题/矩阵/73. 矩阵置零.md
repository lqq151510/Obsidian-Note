## 一、题目描述

**73. 矩阵置零（Set Matrix Zeroes）**​

难度：中等

给定一个 `m x n`的矩阵，如果一个元素为 `0`，则将其**所在行和所在列**的所有元素都设为 `0`。

⚠️ 要求使用 **原地算法**（不使用额外矩阵）。

### 示例 1

```
输入:
[
  [1, 1, 1],
  [1, 0, 1],
  [1, 1, 1]
]

输出:
[
  [1, 0, 1],
  [0, 0, 0],
  [1, 0, 1]
]
```

### 示例 2

```
输入:
[
  [0, 1, 2, 0],
  [3, 4, 5, 2],
  [1, 3, 1, 5]
]

输出:
[
  [0, 0, 0, 0],
  [0, 4, 5, 0],
  [0, 3, 1, 0]
]
```

---

## 二、解题思路（原地算法）

### 核心思想

利用矩阵本身的 **第一行和第一列**​ 作为标记位，记录某一行或某一列是否需要置零。

### 关键点

1. 先用两个布尔变量标记：
    
    - `firstRowZero`：第一行是否原本含有 `0`
        
    - `firstColZero`：第一列是否原本含有 `0`
        
    
2. 从第 `(1,1)`个元素开始遍历：
    
    - 若 `matrix[i][j] == 0`，则：
        
        ```
        matrix[i][0] = 0;
        matrix[0][j] = 0;
        ```
        
    
3. 再次遍历，根据标记置零（跳过第一行和第一列）
    
4. 最后根据 `firstRowZero`和 `firstColZero`处理第一行和第一列
    

✅ **空间复杂度 O(1)，原地修改**

---

## 三、Java 实现代码

```
class Solution {
    public void setZeroes(int[][] matrix) {
        int m = matrix.length;
        int n = matrix[0].length;

        boolean firstRowZero = false;
        boolean firstColZero = false;

        // 检查第一行是否有 0
        for (int j = 0; j < n; j++) {
            if (matrix[0][j] == 0) {
                firstRowZero = true;
                break;
            }
        }

        // 检查第一列是否有 0
        for (int i = 0; i < m; i++) {
            if (matrix[i][0] == 0) {
                firstColZero = true;
                break;
            }
        }

        // 使用第一行和第一列作为标记
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }

        // 根据标记置零（不包含第一行和第一列）
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }

        // 处理第一行
        if (firstRowZero) {
            for (int j = 0; j < n; j++) {
                matrix[0][j] = 0;
            }
        }

        // 处理第一列
        if (firstColZero) {
            for (int i = 0; i < m; i++) {
                matrix[i][0] = 0;
            }
        }
    }
}
```
