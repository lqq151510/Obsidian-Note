
## 题目描述

给你二叉树的根节点 `root`，返回其节点值的 **层序遍历**（即逐层地，从左到右访问所有节点）。

## 示例

**示例 1：**

输入：`root = [3,9,20,null,null,15,7]`

输出：`[[3],[9,20],[15,7]]`

**示例 2：**

输入：`root = [1]`

输出：`[[1]]`

**示例 3：**

输入：`root = []`

输出：`[]`

## 解法：使用队列的BFS算法

```
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) {
            return result;
        }
        
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        
        while (!queue.isEmpty()) {
            int size = queue.size();
            List<Integer> current = new ArrayList<>();
            
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                current.add(node.val);
                
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
            result.add(current);
        }
        return result;
    }
}
```

## 算法思路

1. 使用队列（Queue）实现广度优先搜索（BFS）
    
2. 每次处理一层节点，先记录当前队列的大小（即该层的节点数）
    
3. 遍历当前层所有节点：
    
    - 从队列中取出节点
        
    - 将节点值加入当前层列表
        
    - 将节点的左右子节点（如果存在）加入队列
        
    
4. 将当前层列表加入结果列表
    
5. 重复上述步骤直到队列为空
    

## 复杂度分析

- **时间复杂度**：O(n)，其中 n 是二叉树的节点数，每个节点恰好被访问一次
    
- **空间复杂度**：O(n)，队列中元素个数不超过 n
    

## 测试用例

```
public class Test {
    public static void main(String[] args) {
        Solution solution = new Solution();
        
        // 测试用例1
        TreeNode root1 = new TreeNode(3);
        root1.left = new TreeNode(9);
        root1.right = new TreeNode(20);
        root1.right.left = new TreeNode(15);
        root1.right.right = new TreeNode(7);
        System.out.println("测试1: " + solution.levelOrder(root1)); // [[3], [9, 20], [15, 7]]
        
        // 测试用例2
        TreeNode root2 = new TreeNode(1);
        System.out.println("测试2: " + solution.levelOrder(root2)); // [[1]]
        
        // 测试用例3
        TreeNode root3 = null;
        System.out.println("测试3: " + solution.levelOrder(root3)); // []
    }
}
```

## 相关算法

1. **广度优先搜索（BFS）**：通过队列实现，逐层遍历
    
2. **深度优先搜索（DFS）**：也可以实现，但需要记录层数信息
    
3. **双端队列**：在某些变体问题中可以使用
    

## 扩展

- **自底向上的层序遍历**：从最底层到最顶层的层序遍历
    
- **Z字形层序遍历**：奇数层从左到右，偶数层从右到左
    
- **N叉树的层序遍历**：类似，但每个节点可能有多个子节点
    

## 应用场景

1. 二叉树的最小深度
    
2. 二叉树的右视图
    
3. 二叉树的层次平均值
    
4. 二叉树的锯齿形层序遍历
    

## 注意事项

1. 注意处理空树的情况
    
2. 使用队列时注意判空
    
3. 每次循环开始时记录当前队列的大小，这个大小就是当前层的节点数
