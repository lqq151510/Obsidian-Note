

## 问题描述

给定一个整数数组 `nums`，请找出一个具有**最大和**的连续子数组（子数组至少包含一个元素），并返回其最大和。

**子数组**​ 是数组中的一个连续部分。

## 示例

**示例 1:**

```
输入: nums = [-2,1,-3,4,-1,2,1,-5,4]
输出: 6
解释: 连续子数组 [4,-1,2,1] 的和最大，为 6。
```

**示例 2:**

```
输入: nums = [1]
输出: 1
```

**示例 3:**

```
输入: nums = [5,4,-1,7,8]
输出: 23
```

## 算法思路

本题使用经典的 **Kadane 算法**（动态规划思想）：

1. **状态定义**：
    
    - `currentMax`：以当前元素结尾的最大子数组和
        
    - `globalMax`：全局最大子数组和
        
    
2. **状态转移方程**：
    
    - 对于每个元素 `nums[i]`，有两种选择：
        
        - 将其加入前面的子数组：`currentMax + nums[i]`
            
        - 以当前元素开始新的子数组：`nums[i]`
            
        
    - 取两者中的较大值：`currentMax = max(currentMax + nums[i], nums[i])`
        
    
3. **更新全局最大值**：
    
    - 每次计算完当前最大值后，更新全局最大值：`globalMax = max(globalMax, currentMax)`
        
    

## 代码实现

```
class Solution {
    public int maxSubArray(int[] nums) {
        // 边界情况：数组为空（题目保证至少有一个元素）
        if (nums == null || nums.length == 0) {
            return 0;
        }
        
        // 初始化：当前最大和与全局最大和均为第一个元素
        int currentMax = nums[0];
        int globalMax = nums[0];
        
        // 从第二个元素开始遍历
        for (int i = 1; i < nums.length; i++) {
            // 核心决策：要么继续扩展当前子数组，要么重新开始
            // 取两者中的较大值作为新的当前最大和
            currentMax = Math.max(currentMax + nums[i], nums[i]);
            
            // 更新全局最大和
            globalMax = Math.max(globalMax, currentMax);
        }
        
        return globalMax;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，其中 n 是数组的长度。只需遍历数组一次。
    
- **空间复杂度**：O(1)，只使用了常数个额外变量。
    

## 算法演示

以 `nums = [-2,1,-3,4,-1,2,1,-5,4]`为例：

|索引|元素|currentMax|globalMax|
|---|---|---|---|
|0|-2|-2|-2|
|1|1|max(-2+1, 1) = 1|max(-2, 1) = 1|
|2|-3|max(1-3, -3) = -2|max(1, -2) = 1|
|3|4|max(-2+4, 4) = 4|max(1, 4) = 4|
|4|-1|max(4-1, -1) = 3|max(4, 3) = 4|
|5|2|max(3+2, 2) = 5|max(4, 5) = 5|
|6|1|max(5+1, 1) = 6|max(5, 6) = 6|
|7|-5|max(6-5, -5) = 1|max(6, 1) = 6|
|8|4|max(1+4, 4) = 5|max(6, 5) = 6|

最终结果为 **6**，对应的子数组为 `[4, -1, 2, 1]`。

## 扩展思考

1. **如何处理全为负数的情况？**
    
    - 算法同样适用。例如 `nums = [-3, -1, -2]`，结果会是 `-1`。
        
    
2. **如果需要返回最大子数组本身，而不仅仅是和？**
    
    - 可以额外记录子数组的起始和结束位置。
        
    
3. **分治法解法**
    
    - 也可以用分治法解决，时间复杂度同样是 O(n)，但代码更复杂。
