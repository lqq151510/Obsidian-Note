## 一、题目整理

**LeetCode 153：寻找旋转排序数组中的最小值（中等）**

### 题目描述

- 给定一个长度为 `n`的数组 `nums`
    
- 原始数组是 **严格升序排列**
    
- 经过 **1 到 n 次旋转**（向右旋转）
    
- 数组元素 **互不相同**
    
- 要求：**在时间复杂度 O(log n) 内找到最小值**
    

### 示例

|原数组|旋转次数|结果数组|
|---|---|---|
|[0,1,2,4,5,6,7]|4|[4,5,6,7,0,1,2]|
|[0,1,2,4,5,6,7]|7|[0,1,2,4,5,6,7]|

---

## 二、解题思路（二分查找）

### 核心观察

- 旋转后的数组可以分为 **两个有序区间**
    
- **最小值一定出现在“断崖”处**
    
- 比较 `nums[mid]`和 `nums[right]`可以判断最小值在哪一侧
    

### 判断规则

|情况|说明|操作|
|---|---|---|
|`nums[mid] > nums[right]`|左侧有序，最小值在右侧|`left = mid + 1`|
|`nums[mid] <= nums[right]`|右侧有序，最小值在左侧或就是 mid|`right = mid`|

### 终止条件

- 当 `left == right`时，指针正好指向最小值
    

---

## 三、你的代码（推荐版本 ✅）

你的第二段代码逻辑非常标准，**这是面试中最常用写法**：

```
class Solution {
    public int findMin(int[] nums) {
        int left = 0;
        int right = nums.length - 1;

        while (left < right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] > nums[right]) {
                // 最小值在 mid 右侧
                left = mid + 1;
            } else {
                // 最小值在 mid 左侧（或就是 mid）
                right = mid;
            }
        }

        return nums[left];
    }
}
```

## 五、常见误区提醒 ⚠️

1. ❌ 不要用 `nums[mid]`和 `nums[left]`比较（容易出错）
    
2. ✅ 用 `nums[mid]`vs `nums[right]`是最稳定的方式
    
3. ❌ 不要写成 `right = mid - 1`（可能会跳过最小值）
