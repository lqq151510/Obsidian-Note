

**问题描述**：

给定一个字符串 `s`，将其划分为**尽可能多**的片段，满足：

1. 同一字母最多出现在一个片段中；
    
2. 所有划分结果按顺序连接后等于原字符串 `s`。
    
    返回每个片段长度的列表。
    

**示例**：

输入：`s = "ababcc"`

输出：`[4,2]`

解释：合法划分为 `"abab"`和 `"cc"`（同一字母未跨片段）；非法划分如 `["aba","bcc"]`（`'a'`跨片段）、`["ab","ab","cc"]`（未尽可能多划分）。

### 代码整理（Java）

```
class Solution {
    public List<Integer> partitionLabels(String s) {
        // 第一步：记录每个小写字母最后一次出现的下标（共26个字母）
        int[] last = new int[26];
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i; // 更新字母最后出现的位置
        }
        
        List<Integer> result = new ArrayList<>();
        int start = 0; // 当前片段的起始下标
        int end = 0;   // 当前片段能覆盖的最远下标（由片段内字母的最后位置决定）
        
        // 第二步：贪心遍历，划分片段
        for (int i = 0; i < s.length(); i++) {
            // 更新当前片段的最远边界：取当前字母最后位置和已有end的最大值
            end = Math.max(end, last[s.charAt(i) - 'a']);
            
            // 当遍历到下标等于当前片段的最远边界时，完成一个片段划分
            if (i == end) {
                result.add(end - start + 1); // 片段长度 = 结束下标 - 起始下标 +1
                start = i + 1; // 下一个片段的起始为当前下标+1
            }
        }
        return result;
    }
}
```

### 代码逻辑说明

该解法采用**贪心策略**，核心思路：

1. **预处理**：先记录每个字母的最后出现位置，确保所有相同字母都被包含在同一个片段内；
    
2. **动态划界**：遍历字符串时，用 `end`维护当前片段能覆盖的最远位置（即片段内所有字母最后位置的最大值）；
    
3. **触发划分**：当遍历到下标 `i`等于 `end`时，说明当前片段内的字母不会再出现在后续位置，即可安全划分。
    

**复杂度分析**：

- 时间复杂度：`O(n)`（`n`为字符串长度，两次遍历均为线性时间）；
    
- 空间复杂度：`O(1)`（仅用固定大小的数组存储26个字母的最后位置）。
