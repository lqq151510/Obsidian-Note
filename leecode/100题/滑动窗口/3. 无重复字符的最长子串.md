



**题目描述**：给定一个字符串 `s`，请你找出其中不含有重复字符的 **最长**​ 子串的长度。

#### 示例

|输入|输出|说明|
|---|---|---|
|`"abcabcbb"`|3|最长子串为 `"abc"`|
|`"bbbbb"`|1|最长子串为 `"b"`|
|`"pwwkew"`|3|最长子串为 `"wke"`或 `"kew"`|

---

### 代码实现（Java）

```
import java.util.HashMap;
import java.util.Map;

public class Solution {
    public int lengthOfLongestSubstring(String s) {
        // 哈希表存储字符最后出现的索引
        Map<Character, Integer> lastIndex = new HashMap<>();
        int left = 0;          // 滑动窗口左边界
        int maxLength = 0;     // 最长子串长度
        
        for (int right = 0; right < s.length(); right++) {
            char ch = s.charAt(right);
            // 若字符已存在且在当前窗口内，移动左边界到重复字符的下一位
            if (lastIndex.containsKey(ch) && lastIndex.get(ch) >= left) {
                left = lastIndex.get(ch) + 1;
            }
            // 更新字符最后出现的位置
            lastIndex.put(ch, right);
            // 更新最大长度（当前窗口长度为 right - left + 1）
            maxLength = Math.max(maxLength, right - left + 1);
        }
        return maxLength;
    }
}
```

---

### 关键思路说明

- **滑动窗口**：用 `left`和 `right`双指针维护一个无重复字符的窗口 `[left, right]`；
    
- **哈希表优化**：记录每个字符最后一次出现的索引，避免每次判断重复时线性扫描；
    
- **时间复杂度**：`O(n)`（`n`为字符串长度，每个字符仅被访问一次）；
    
- **空间复杂度**：`O(min(m, n))`（`m`为字符集大小，如 ASCII 为 128）。
