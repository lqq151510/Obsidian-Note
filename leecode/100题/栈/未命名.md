## 题目描述

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string`正好重复 `k`次。注意 `k`保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k`，例如不会出现像 `3a`或 `2[4]`的输入。

测试用例保证输出的长度不会超过 10^5。

**示例 1：**

```
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

**示例 2：**

```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

**示例 3：**

```
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
```

## 解题思路：双栈法

使用两个栈分别存储数字（重复次数）和字符串（当前层级之前的前缀）。遍历字符串：

- 遇到数字：累积成整数（处理多位数字）。
    
- 遇到左括号 `[`：将当前数字和字符串分别入栈，然后重置。
    
- 遇到右括号 `]`：弹出数字栈顶得到重复次数，弹出字符串栈顶得到前缀，将当前字符串重复指定次数后拼接到前缀后，更新为当前字符串。
    
- 遇到字母：直接追加到当前字符串。
    

遍历结束后，当前字符串即为结果。

## 代码实现

```
import java.util.Deque;
import java.util.LinkedList;

class Solution {
    public String decodeString(String s) {
        // 数字栈，用于保存重复次数k
        Deque<Integer> numStack = new LinkedList<>();
        // 字符串栈，用于保存括号前的字符串片段
        Deque<String> strStack = new LinkedList<>();
        
        // 当前正在构建的字符串
        StringBuilder curStr = new StringBuilder();
        // 当前解析到的数字
        int num = 0;
        
        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                // 处理多位数字，如"100"
                num = num * 10 + (c - '0');
            } else if (c == '[') {
                // 遇到左括号，将当前状态入栈，并重置
                numStack.push(num);
                strStack.push(curStr.toString());
                num = 0;
                curStr = new StringBuilder();
            } else if (c == ']') {
                // 遇到右括号，出栈并计算结果
                int repeatTimes = numStack.pop();
                StringBuilder temp = new StringBuilder(strStack.pop());
                
                // 将当前字符串重复repeatTimes次
                for (int i = 0; i < repeatTimes; i++) {
                    temp.append(curStr);
                }
                curStr = temp;
            } else {
                // 普通字母字符，直接追加
                curStr.append(c);
            }
        }
        
        return curStr.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)，其中 N 是解码后字符串的长度。每个字符处理一次，栈操作均摊 O(1)。
    
- **空间复杂度**：O(M)，其中 M 是输入字符串中括号的嵌套层数，最坏情况下为 O(N)。
