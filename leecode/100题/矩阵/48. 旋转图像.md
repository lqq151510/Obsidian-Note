
## 题目描述

给定一个 `n × n`的二维矩阵 `matrix`表示一个图像。请你将图像**顺时针旋转 90 度**。

你必须在**原地**旋转图像，这意味着你需要直接修改输入的二维矩阵。**请不要使用另一个矩阵**来旋转图像。

## 解决方案代码（Java）

```
class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;

        // 1. 转置矩阵：沿主对角线（左上到右下）交换元素
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int temp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = temp;
            }
        }

        // 2. 镜像翻转：每一行左右进行对称交换
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n / 2; j++) {
                int temp = matrix[i][j];
                matrix[i][j] = matrix[i][n - 1 - j];
                matrix[i][n - 1 - j] = temp;
            }
        }
    }
}
```

## 算法思路

1. **转置矩阵**：将矩阵沿主对角线翻转，即 `matrix[i][j]`与 `matrix[j][i]`交换。
    
2. **水平镜像翻转**：将每一行的元素左右反转，即第 `i`行中 `matrix[i][j]`与 `matrix[i][n-1-j]`交换。
    

这两步操作即可实现原地的顺时针 90° 旋转。
