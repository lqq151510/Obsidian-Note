
## 📘 题目描述

你这个学期必须选修 `numCourses`门课程，记为 `0`到 `numCourses - 1`。

某些课程之间存在先修关系，用一个二维数组 `prerequisites`表示：

```
prerequisites[i] = [ai, bi]
```

表示：**要学习课程 `ai`，必须先完成课程 `bi`**。

请判断是否有可能完成所有课程的学习：

- ✅ 可以完成 → 返回 `true`
    
- ❌ 存在循环依赖 → 返回 `false`
    

---

## 💡 解题思路（拓扑排序 · BFS）

- 将课程看作 **有向图**：
    
    - 节点：课程
        
    - 边：`bi → ai`
        
    
- 统计每门课程的 **入度**
    
- 从 **入度为 0**​ 的课程开始学习
    
- 每学一门课，减少后续课程的入度
    
- 若出现环，则无法完成全部课程
    

---

## ✅ Java 实现（你的代码，已整理）

```
import java.util.*;

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 1. 构建邻接表和入度数组
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            adj.add(new ArrayList<>());
        }

        int[] indegree = new int[numCourses];
        for (int[] p : prerequisites) {
            int course = p[0];
            int pre = p[1];
            adj.get(pre).add(course);
            indegree[course]++;
        }

        // 2. 将所有入度为 0 的课程加入队列
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if (indegree[i] == 0) {
                queue.offer(i);
            }
        }

        // 3. BFS 拓扑排序
        int finished = 0;
        while (!queue.isEmpty()) {
            int curr = queue.poll();
            finished++;

            for (int next : adj.get(curr)) {
                indegree[next]--;
                if (indegree[next] == 0) {
                    queue.offer(next);
                }
            }
        }

        // 4. 判断是否完成所有课程
        return finished == numCourses;
    }
}
```
