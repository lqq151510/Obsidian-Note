
## 一、题目回顾

**题意**​

给定一棵二叉树 `root`，将其 **原地**​ 展开为一个单链表：

- 使用二叉树节点 `TreeNode`
    
- 展开后：
    
    - `right`指向下一个节点
        
    - `left`全部置为 `null`
        
    
- 展开顺序：**先序遍历（根 → 左 → 右）**
    

---

## 二、核心思路（O(1) 空间）

### 思路名称

✅ **寻找前驱节点（Morris 变形）**

### 关键观察

对于每个节点 `curr`：

1. 如果 `curr.left != null`
    
2. 找到 **左子树中最右的节点**（即先序遍历中，`curr`的后继）
    
3. 把这个最右节点的 `right`指向 `curr.right`
    
4. 把 `curr.right`指向 `curr.left`
    
5. 清空 `curr.left`
    

👉 本质：

**把左子树“插入”到当前节点和右子树之间**

---

## 三、执行流程示意

```
原树：
    1
   / \
  2   5
 / \   \
3   4   6

展开后：
1 → 2 → 3 → 4 → 5 → 6
```

## 四、整理后的 Java 代码（推荐版本）

```
/**
 * Definition for a binary tree node.
 */
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}
    TreeNode(int val) {
        this.val = val;
    }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    /**
     * 将二叉树展开为单链表（原地）
     */
    public void flatten(TreeNode root) {
        TreeNode curr = root;

        while (curr != null) {

            // 情况 1：存在左子树，需要处理
            if (curr.left != null) {

                // 1️⃣ 找到左子树的最右节点（前驱节点）
                TreeNode predecessor = curr.left;
                while (predecessor.right != null) {
                    predecessor = predecessor.right;
                }

                // 2️⃣ 将原右子树接到前驱节点后面
                predecessor.right = curr.right;

                // 3️⃣ 将左子树移到右边
                curr.right = curr.left;
                curr.left = null;
            }

            // 4️⃣ 处理下一个节点
            curr = curr.right;
        }
    }
}
```

public class Solution114 {
    public void flatten(TreeNode root) {
        TreeNode curr = root;
        while (curr != null) {
            if (curr.left != null) {
                TreeNode pre = curr.left;
                while (pre.right != null) pre = pre.right;
                pre.right = curr.right;
                curr.right = curr.left;
                curr.left = null;
            }
            curr = curr.right;
        }
    }
}
