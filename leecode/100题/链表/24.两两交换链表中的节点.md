

**描述**：给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

**示例**：

- 输入：`head = [1,2,3,4]`
    
- 输出：`[2,1,4,3]`
    
    **关键点**：
    
- 不能修改节点值，只能通过改变指针完成交换。
    
- 若链表长度为奇数，最后一个节点保持不变。
    

---

### 代码总结

```
class Solution {
    public ListNode swapPairs(ListNode head) {
        // 1. 创建虚拟头节点，指向原链表头
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        // 当前指针，初始指向虚拟头节点（始终指向待交换两个节点的前一个节点）
        ListNode curr = dummy;

        // 循环条件：剩余节点至少有2个，才需要交换
        while (curr.next != null && curr.next.next != null) {
            // 定义待交换的两个节点：左节点、右节点
            ListNode left = curr.next;
            ListNode right = curr.next.next;

            // 核心：三步指针交换，完成两两交换
            left.next = right.next;  // 1. 左节点指向右节点的下一个节点
            right.next = left;       // 2. 右节点指向左节点（完成交换）
            curr.next = right;       // 3. 前一个节点指向交换后的头节点（右节点）

            // 指针后移，准备交换下一对节点
            curr = left;
        }

        // 返回交换后的链表头
        return dummy.next;
    }
}
```

#### 算法思路

- **虚拟头节点**：简化边界处理（如头节点参与交换的情况）。
    
- **迭代交换**：每次处理一对相邻节点，通过三步指针重连实现交换：
    
    1. 左节点指向右节点的后继。
        
    2. 右节点指向左节点。
        
    3. 前驱节点指向右节点（新头部）。
        
    
- **指针推进**：交换后，`curr`移动到交换对的第二个节点（原左节点），作为下一对的前驱。
    
- **时间复杂度**：O(n)，每个节点仅访问一次。
    
- **空间复杂度**：O(1)，仅使用常数额外空间。
    

该方法高效且直观，是链表两两交换的经典解法。
