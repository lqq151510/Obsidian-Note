

### 📌 题目描述

数字 `n`代表生成括号的对数，请你设计一个函数，用于生成**所有可能的**、**有效的**括号组合。

**示例：**

```
输入：n = 3
输出：[
       "((()))",
       "(()())",
       "(())()",
       "()(())",
       "()()()"
     ]
```

---

### 💡 解题思路（回溯 / 剪枝）

这是一道经典的 **回溯 + 约束条件**​ 问题。

核心规则：

1. **左括号 `(`**​
    
    - 只要数量小于 `n`，就可以继续添加
        
    
2. **右括号 `)`**​
    
    - 只有当已使用的右括号少于左括号时，才能添加
        
    
3. **终止条件**​
    
    - 字符串长度等于 `2 * n`
        
    

这样可以保证：

- 括号始终合法
    
- 不会生成无效组合（如 `")("`）
    

---

### ✅ Java 实现（推荐写法）

```
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> result = new ArrayList<>();
        backtrack(result, "", 0, 0, n);
        return result;
    }

    private void backtrack(
            List<String> result,
            String current,
            int open,
            int close,
            int max) {

        // 终止条件：括号已全部用完
        if (current.length() == max * 2) {
            result.add(current);
            return;
        }

        // 如果还可以放左括号
        if (open < max) {
            backtrack(result, current + "(", open + 1, close, max);
        }

        // 如果右括号少于左括号
        if (close < open) {
            backtrack(result, current + ")", open, close + 1, max);
        }
    }
}
```

### ⏱️ 复杂度分析

|指标|说明|
|---|---|
|时间复杂度|**O(4ⁿ / √n)**（卡特兰数）|
|空间复杂度|**O(n)**（递归栈深度）|

- 面试中常问：**如何剪枝？为什么不会重复？**
