# vercel-react

## Goal
Ship fast React apps on Vercel with strong performance.

## Workflow
1. Optimize bundle, route splitting, and image strategy.
2. Configure environment variables and preview checks.
3. Validate core web vitals and runtime errors.
4. Prepare deploy checklist and rollback notes.

## Output format
- Perf checklist
- Build/deploy steps
- Post-deploy verification
