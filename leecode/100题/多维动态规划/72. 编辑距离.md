## 一、题目描述

**题目：72. 编辑距离（Edit Distance）**​

**难度：中等**

给你两个单词 `word1`和 `word2`，请返回将 `word1`转换成 `word2`所使用的最少操作数。

你可以对一个单词进行如下三种操作：

- 插入一个字符
    
- 删除一个字符
    
- 替换一个字符
    

---

## 二、示例

|输入|输出|说明|
|---|---|---|
|`word1 = "horse", word2 = "ros"`|`3`|`horse → rorse`（替换 h→r）  <br>`rorse → rose`（删除 r）  <br>`rose → ros`（删除 e）|
|`word1 = "intention", word2 = "execution"`|`5`|`intention → inention`（删除 t）  <br>`inention → enention`（替换 i→e）  <br>`enention → exention`（替换 n→x）  <br>`exention → exection`（替换 n→c）  <br>`exection → execution`（插入 u）|

---

## 三、解题思路（动态规划 ✅）

### 核心思想

使用二维动态规划，`dp[i][j]`表示将 `word1`的前 `i`个字符转换成 `word2`的前 `j`个字符所需的最少操作数。

### 状态转移方程

- 如果 `word1.charAt(i-1) == word2.charAt(j-1)`：
    
    `dp[i][j] = dp[i-1][j-1]`（无需操作）
    
- 否则：
    
    `dp[i][j] = min(dp[i-1][j] + 1, dp[i][j-1] + 1, dp[i-1][j-1] + 1)`
    
    分别对应：删除、插入、替换
    

### 初始化

- `dp[i][0] = i`（将 `word1`前 `i`个字符全部删除）
    
- `dp[0][j] = j`（向空字符串插入 `j`个字符）
    

### 最终结果

- `dp[m][n]`（`m`和 `n`分别是两个单词的长度）

## 四、Java 代码实现（推荐 ✅）

```
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        
        // dp[i][j] 表示 word1 前 i 个字符转换成 word2 前 j 个字符的最少操作数
        int[][] dp = new int[m + 1][n + 1];
        
        // 初始化：将 word1 前 i 个字符转换成空字符串，需要 i 次删除操作
        for (int i = 0; i <= m; i++) {
            dp[i][0] = i;
        }
        // 初始化：将空字符串转换成 word2 前 j 个字符，需要 j 次插入操作
        for (int j = 0; j <= n; j++) {
            dp[0][j] = j;
        }
        
        // 填充 dp 数组
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    // 字符相同，无需操作
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    // 字符不同，取三种操作的最小值
                    dp[i][j] = Math.min(
                        dp[i - 1][j] + 1,      // 删除 word1 的第 i 个字符
                        Math.min(
                            dp[i][j - 1] + 1,   // 在 word1 中插入 word2 的第 j 个字符
                            dp[i - 1][j - 1] + 1 // 替换 word1 的第 i 个字符为 word2 的第 j 个字符
                        )
                    );
                }
            }
        }
        
        return dp[m][n];
    }
}
```

## 七、面试要点 ✅

- ✅ 动态规划是标准解法，必须熟练掌握
    
- ✅ 注意字符串索引与 dp 数组索引的对应关系（`i-1`和 `j-1`）
    
- ✅ 初始化时，第一行和第一列分别表示删除和插入操作
    
- ✅ 最终答案在 `dp[m][n]`
    

---

## 八、常见错误 ❌

|错误|说明|
|---|---|
|混淆操作类型|删除、插入、替换对应不同的 dp 转移|
|索引越界|忘记处理 `i-1`和 `j-1`|
|未正确初始化|导致错误结果|

## 九、空间优化（一维 DP）

可以使用一维数组优化空间复杂度至 **O(n)**：

```
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        int[] dp = new int[n + 1];
        
        // 初始化第一行
        for (int j = 0; j <= n; j++) {
            dp[j] = j;
        }
        
        for (int i = 1; i <= m; i++) {
            int prev = dp[0]; // dp[i-1][0]
            dp[0] = i; // dp[i][0]
            for (int j = 1; j <= n; j++) {
                int temp = dp[j]; // 保存当前 dp[j]，作为下一次的 prev
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[j] = prev;
                } else {
                    dp[j] = Math.min(Math.min(dp[j], dp[j - 1]), prev) + 1;
                }
                prev = temp;
            }
        }
        return dp[n];
    }
}
```
