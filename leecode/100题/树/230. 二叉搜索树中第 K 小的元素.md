
## 题目描述

给定一个二叉搜索树的根节点 `root`，和一个整数 `k`，请你设计一个算法查找其中第 `k`小的元素（从 1 开始计数）。

## 示例

```
输入：root = [3,1,4,null,2], k = 1
输出：1
```

```
输入：root = [5,3,6,2,4,null,null,1], k = 3
输出：3
```

## 解题思路

利用二叉搜索树的中序遍历特性：中序遍历 BST 会得到一个递增序列。因此，第 k 小的元素即为中序遍历的第 k 个节点。

这里使用**非递归中序遍历**（迭代 + 栈）来节省空间（无需存储整个序列）。

## 代码实现（Java）

```
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int kthSmallest(TreeNode root, int k) {
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode curr = root;
        
        while (curr != null || !stack.isEmpty()) {
            // 1. 尽可能向左走，将路径上的节点压入栈
            while (curr != null) {
                stack.push(curr);
                curr = curr.left;
            }
            
            // 2. 弹出栈顶节点（即当前最小的节点）
            curr = stack.pop();
            k--; // 计数
            
            // 3. 如果是第 k 个，直接返回结果
            if (k == 0) {
                return curr.val;
            }
            
            // 4. 转向右子树
            curr = curr.right;
        }
        return -1; // 理论上不会走到这里
    }
}
```

## 复杂度分析

- **时间复杂度**：O(H + k)，其中 H 是树的高度。在最坏情况下（链表状树）为 O(n)。
    
- **空间复杂度**：O(H)，栈的最大深度等于树的高度。最坏情况为 O(n)。
    

## 补充说明

该解法适用于一般情况，若需要多次调用 `kthSmallest`，可提前统计每个节点的子树大小，将时间优化至 O(log n)。
