## 一、题目描述

**题目：4. 寻找两个正序数组的中位数（Median of Two Sorted Arrays）**​

**难度：困难**

给定两个大小分别为 `m`和 `n`的**正序（从小到大）数组**​ `nums1`和 `nums2`。请你找出并返回这两个正序数组的 **中位数**。

### 要求

- 时间复杂度必须为 **O(log(m+n))**
    
- 不能合并数组后再求中位数（那样是 O(m+n)）
    

---

## 二、示例

|输入|输出|说明|
|---|---|---|
|`nums1 = [1,3], nums2 = [2]`|`2.0`|合并后 `[1,2,3]`，中位数为 2|
|`nums1 = [1,2], nums2 = [3,4]`|`2.5`|合并后 `[1,2,3,4]`，中位数 `(2+3)/2=2.5`|
|`nums1 = [], nums2 = [1]`|`1.0`|只有一个元素|

---

## 三、解题思路（二分查找 + 分割线思想 ✅）

### 核心目标

将两个数组划分为左右两部分，使得：

- 左边元素个数 = 右边元素个数（或左边多一个）
    
- 左边所有元素 ≤ 右边所有元素
    

### 关键公式

假设从 `nums1`中取 `i`个元素，从 `nums2`中取 `j`个元素放入左边：

```
i + j = (m + n + 1) / 2
```

### 二分查找

- 在 `nums1`上二分查找合适的 `i`
    
- 保证：
    
    ```
    nums1[i-1] ≤ nums2[j]
    nums2[j-1] ≤ nums1[i]
    ```

## 四、Java 代码实现（推荐 ✅）

```
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        // 确保 nums1 是较短的数组，减少二分次数
        if (nums1.length > nums2.length) {
            return findMedianSortedArrays(nums2, nums1);
        }

        int m = nums1.length;
        int n = nums2.length;
        int totalLeft = (m + n + 1) / 2;

        int left = 0, right = m;

        while (left <= right) {
            int i = left + (right - left) / 2; // nums1 左边元素个数
            int j = totalLeft - i;             // nums2 左边元素个数

            int nums1LeftMax = (i == 0) ? Integer.MIN_VALUE : nums1[i - 1];
            int nums1RightMin = (i == m) ? Integer.MAX_VALUE : nums1[i];
            int nums2LeftMax = (j == 0) ? Integer.MIN_VALUE : nums2[j - 1];
            int nums2RightMin = (j == n) ? Integer.MAX_VALUE : nums2[j];

            if (nums1LeftMax <= nums2RightMin && nums2LeftMax <= nums1RightMin) {
                // 找到正确分割
                if ((m + n) % 2 == 0) {
                    return (Math.max(nums1LeftMax, nums2LeftMax) +
                            Math.min(nums1RightMin, nums2RightMin)) / 2.0;
                } else {
                    return Math.max(nums1LeftMax, nums2LeftMax);
                }
            } else if (nums1LeftMax > nums2RightMin) {
                right = i - 1;
            } else {
                left = i + 1;
            }
        }

        return 0.0;
    }
}
```

|空间复杂度|**O(1)**​|

## 六、执行过程示意

以 `nums1 = [1,3], nums2 = [2]`为例：

```
nums1: [1 | 3]
nums2: [2 | ]
```

- 左边最大值：`max(1,2) = 2`
    
- 右边最小值：`min(3,∞) = 3`
    
- 总数为奇数 → 中位数 = `2`
    

---

## 七、面试要点 ✅

- ✅ 必须在较短数组上二分
    
- ✅ 处理边界时使用 `Integer.MIN_VALUE`/ `MAX_VALUE`
    
- ✅ 区分奇数和偶数情况
    
- ✅ 不要合并数组
    

---

## 八、常见错误 ❌

|错误|说明|
|---|---|
|直接合并数组|时间复杂度 O(m+n)，不符合要求|
|忽略边界条件|i=0、j=0、i=m、j=n 的情况|
|二分逻辑错误|没有正确调整 left / right|
