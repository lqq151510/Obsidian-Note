## 题目描述

**题目：缺失的第一个正数（First Missing Positive）**​

**难度：困难**

给你一个未排序的整数数组 `nums`，请你找出其中 **没有出现的最小正整数**。

**要求：**

- 时间复杂度：**O(n)**
    
- 额外空间复杂度：**O(1)**（常数级）
    

---

## 示例

|输入|输出|说明|
|---|---|---|
|`[1,2,0]`|`3`|最小未出现的正整数是 3|
|`[3,4,-1,1]`|`2`|最小未出现的正整数是 2|
|`[7,8,9,11,12]`|`1`|最小未出现的正整数是 1|

---

## 解题思路（核心思想）

使用 **原地哈希（in-place hashing）**：

- 理想情况下，数组应变为：
    
    `[1, 2, 3, ..., n]`
    
- 将数值 `x`（满足 `1 ≤ x ≤ n`）放到索引 `x - 1`的位置
    
- 最后扫描数组，第一个 `nums[i] != i + 1`的位置即为答案
    
- 若全部匹配，则答案为 `n + 1`
    

---

## Java 代码实现 ✅

```
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;

        // 将每个数放到它应该在的位置
        for (int i = 0; i < n; i++) {
            while (nums[i] >= 1 && nums[i] <= n
                    && nums[nums[i] - 1] != nums[i]) {

                // 交换 nums[i] 和 nums[nums[i] - 1]
                int correctIdx = nums[i] - 1;
                int temp = nums[correctIdx];
                nums[correctIdx] = nums[i];
                nums[i] = temp;
            }
        }

        // 查找第一个缺失的正整数
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) {
                return i + 1;
            }
        }

        // 如果所有位置都正确，则缺失的是 n + 1
        return n + 1;
    }
}
```
