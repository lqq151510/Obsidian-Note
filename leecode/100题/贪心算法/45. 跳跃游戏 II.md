

**问题描述**：

给定长度为 `n`的 **0 索引**整数数组 `nums`，初始位置在下标 `0`。每个元素 `nums[i]`表示从索引 `i`向后跳转的最大长度：若你在 `i`处，可跳至 `(i + j)`（`0 ≤ j ≤ nums[i]`且 `i + j < n`）。

**要求**：返回到达 `n - 1`的**最小跳跃次数**（测试用例保证可达）。

### 代码整理（Java）

```
class Solution {
    public int jump(int[] nums) {
        int jump = 0;      // 最小跳跃次数
        int curr = 0;      // 当前跳跃能覆盖的最远边界
        int max = 0;       // 遍历过程中能到达的最远位置

        // 无需遍历最后一个元素（到达终点无需再跳）
        for (int i = 0; i < nums.length - 1; i++) {
            // 更新当前能到达的最远位置
            max = Math.max(max, i + nums[i]);
            
            // 当遍历到当前边界时，必须进行一次跳跃
            if (i == curr) {
                jump++;
                curr = max;  // 更新下一跳的边界
            }
        }
        return jump;
    }
}
```

### 代码逻辑说明

该解法采用**贪心策略**：

- 每次跳跃前，先统计当前跳跃范围内能到达的最远位置 `max`；
    
- 当遍历到当前跳跃的边界 `curr`时，必须进行下一次跳跃（`jump++`），并将边界更新为 `max`（确保下一步覆盖更远的距离）。
    
    时间复杂度 `O(n)`，空间复杂度 `O(1)`。
