## 一、题目描述

**题目：1143. 最长公共子序列（Longest Common Subsequence）**​

**难度：中等**

给定两个字符串 `text1`和 `text2`，返回这两个字符串的 **最长公共子序列**​ 的长度。如果不存在公共子序列，返回 `0`。

**子序列**​ 是指在不改变字符相对顺序的情况下，通过删除某些字符（也可以不删除）得到的新字符串。

例如，`"ace"`是 `"abcde"`的子序列，但 `"aec"`不是。

**公共子序列**​ 是两个字符串共同拥有的子序列。

---

## 二、示例

|输入|输出|说明|
|---|---|---|
|`text1 = "abcde", text2 = "ace"`|`3`|最长公共子序列是 `"ace"`|
|`text1 = "abc", text2 = "abc"`|`3`|两个字符串完全相同|
|`text1 = "abc", text2 = "def"`|`0`|没有公共子序列|

---

## 三、解题思路（动态规划 ✅）

### 核心思想

使用二维动态规划，定义 `dp[i][j]`表示 `text1`的前 `i`个字符与 `text2`的前 `j`个字符的最长公共子序列长度。

### 状态转移方程

- 如果 `text1.charAt(i-1) == text2.charAt(j-1)`：
    
    `dp[i][j] = dp[i-1][j-1] + 1`
    
- 否则：
    
    `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`
    

### 初始化

- `dp[0][j] = 0`（空字符串与任何字符串的公共子序列长度为 0）
    
- `dp[i][0] = 0`
    

### 最终结果

- `dp[m][n]`（`m`和 `n`分别是两个字符串的长度）
    

---

## 四、Java 代码实现（推荐 ✅）

```
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length();
        int n = text2.length();
        
        // dp[i][j] 表示 text1 前 i 个字符和 text2 前 j 个字符的最长公共子序列长度
        int[][] dp = new int[m + 1][n + 1];
        
        // 填充 dp 数组
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    // 当前字符相同，长度加 1
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    // 当前字符不同，取最大值
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        
        return dp[m][n];
    }
}
```

## 七、面试要点 ✅

- ✅ 动态规划是标准解法，必须熟练掌握
    
- ✅ 注意字符串索引与 dp 数组索引的对应关系（`i-1`和 `j-1`）
    
- ✅ 初始化时，第一行和第一列均为 0
    
- ✅ 最终答案在 `dp[m][n]`
    

---

## 八、常见错误 ❌

|错误|说明|
|---|---|
|混淆子序列与子串|子序列可以不连续，子串必须连续|
|索引越界|忘记处理 `i-1`和 `j-1`|
|未初始化 dp 数组|导致错误结果|

## 九、空间优化（一维 DP）

可以使用一维数组优化空间复杂度至 **O(n)**：

```
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length();
        int n = text2.length();
        int[] dp = new int[n + 1];
        
        for (int i = 1; i <= m; i++) {
            int prev = 0; // 相当于 dp[i-1][j-1]
            for (int j = 1; j <= n; j++) {
                int temp = dp[j]; // 保存当前 dp[j]，作为下一次的 prev
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[j] = prev + 1;
                } else {
                    dp[j] = Math.max(dp[j], dp[j - 1]);
                }
                prev = temp;
            }
        }
        return dp[n];
    }
}
```
