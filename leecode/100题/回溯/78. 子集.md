

## 一、题目描述

**难度**：中等

**标签**：回溯、位运算、数组

给你一个整数数组 `nums`，数组中的元素 **互不相同**。

返回该数组 **所有可能的子集（幂集）**。

- 解集 **不能包含重复的子集**
    
- 可 **按任意顺序**​ 返回结果
    

### 示例

```
输入：nums = [1,2,3]
输出：
[
  [],
  [1],
  [2],
  [3],
  [1,2],
  [1,3],
  [2,3],
  [1,2,3]
]
```

### 约束

- `1 ≤ nums.length ≤ 10`
    
- `-10 ≤ nums[i] ≤ 10`
    
- `nums`中 **所有元素互不相同**
    

---

## 二、解题思路（回溯 / 组合型）

### 核心思想

- 每个元素 **可选可不选**
    
- 用 `start`控制起始位置，避免产生重复子集
    
- **每进入一次递归，就收集一次当前路径**
    

### 与「全排列」的区别

|对比点|全排列（46）|子集（78）|
|---|---|---|
|是否关心顺序|✅ 是|❌ 否|
|是否需要 used|✅ 需要|❌ 不需要|
|结束条件|路径长度 = n|遍历完成|
|何时加入结果|只在叶子|**每个节点**​|

## 三、Java 代码（回溯法 ✅）

```
import java.util.*;

class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        backtrack(nums, 0, new ArrayList<>(), result);
        return result;
    }

    private void backtrack(int[] nums, int start,
                           List<Integer> path,
                           List<List<Integer>> result) {

        // 每个节点都是一个合法子集
        result.add(new ArrayList<>(path));

        for (int i = start; i < nums.length; i++) {
            // 选择
            path.add(nums[i]);

            // 递归（i + 1 保证不重复）
            backtrack(nums, i + 1, path, result);

            // 撤销选择
            path.remove(path.size() - 1);
        }
    }
}
```

## 四、递归过程示意（nums = [1,2,3]）

```
[]
├─ [1]
│  ├─ [1,2]
│  │  └─ [1,2,3]
│  └─ [1,3]
├─ [2]
│  └─ [2,3]
└─ [3]
```
