
## 一、题目回顾（51. N 皇后）

- 在 `n × n`棋盘上放置 `n`个皇后
    
- 任意两个皇后 **不能同行、同列、同对角线**
    
- 返回所有合法放置方案
    
- 每个方案用 `'Q'`表示皇后，`'.'`表示空位
    

---

## 二、整理后的 Java 代码（✅ 推荐）

```
import java.util.*;

class Solution {

    // 最终结果
    private List<List<String>> res = new ArrayList<>();

    // 用于剪枝的集合
    private Set<Integer> cols = new HashSet<>();   // 列
    private Set<Integer> diag1 = new HashSet<>();  // 主对角线 row - col
    private Set<Integer> diag2 = new HashSet<>();  // 副对角线 row + col

    public List<List<String>> solveNQueens(int n) {
        backtrack(n, 0, new ArrayList<>());
        return res;
    }

    /**
     * 回溯函数
     * @param n   棋盘大小
     * @param row 当前处理的行
     * @param path 当前路径，path.get(i) 表示第 i 行的皇后放在哪一列
     */
    private void backtrack(int n, int row, List<Integer> path) {
        // 终止条件：所有行都成功放置皇后
        if (row == n) {
            res.add(buildBoard(path));
            return;
        }

        // 尝试在当前行放置皇后
        for (int col = 0; col < n; col++) {
            int d1 = row - col;
            int d2 = row + col;

            // 剪枝：列、主对角线、副对角线冲突检测
            if (cols.contains(col) || diag1.contains(d1) || diag2.contains(d2)) {
                continue;
            }

            // 做选择
            cols.add(col);
            diag1.add(d1);
            diag2.add(d2);
            path.add(col);

            // 递归处理下一行
            backtrack(n, row + 1, path);

            // 撤销选择（回溯）
            path.remove(path.size() - 1);
            diag2.remove(d2);
            diag1.remove(d1);
            cols.remove(col);
        }
    }

    /**
     * 根据列索引构建棋盘
     */
    private List<String> buildBoard(List<Integer> path) {
        int n = path.size();
        List<String> board = new ArrayList<>();

        for (int col : path) {
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < n; i++) {
                sb.append(i == col ? 'Q' : '.');
            }
            board.add(sb.toString());
        }
        return board;
    }
}
```

## 三、关键点总结（面试必说）

### ✅ 为什么只用三个 Set？

|名称|含义|
|---|---|
|`cols`|列是否被占用|
|`diag1`|主对角线 `row - col`|
|`diag2`|副对角线 `row + col`|

👉 **同一对角线上 `row - col`或 `row + col`是常数**

---

### ✅ 回溯三步走

1. **选择**（放皇后）
    
2. **递归**
    
3. **撤销选择**
    

---

### ✅ 时间 & 空间复杂度

|项目|复杂度|
|---|---|
|时间复杂度|O(n!)|
|空间复杂度|O(n)（递归栈 + 集合）|
