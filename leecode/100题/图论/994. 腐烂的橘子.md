
### 📌 题目描述

给定一个 `m x n`的网格 `grid`，每个单元格有三种状态：

|值|含义|
|---|---|
|`0`|空单元格|
|`1`|新鲜橘子 🍊|
|`2`|腐烂橘子 🦠|

**规则：**

- 每分钟，腐烂橘子会使其 **上下左右相邻的新鲜橘子**​ 腐烂
    
- 返回 **所有橘子都腐烂所需的最小分钟数**
    
- 如果不可能全部腐烂，返回 `-1`
    

---

## ☕ Java 代码（多源 BFS · 推荐 ✅）

```
import java.util.LinkedList;
import java.util.Queue;

public class Solution {

    public int orangesRotting(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;

        Queue<int[]> queue = new LinkedList<>();
        int freshCount = 0;

        // 1. 初始化：统计新鲜橘子 & 将所有腐烂橘子加入队列
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) {
                    queue.offer(new int[]{i, j});
                } else if (grid[i][j] == 1) {
                    freshCount++;
                }
            }
        }

        // 如果没有新鲜橘子，直接返回 0
        if (freshCount == 0) return 0;

        int minutes = 0;
        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        // 2. 多源 BFS
        while (!queue.isEmpty()) {
            int size = queue.size();
            boolean hasRot = false;

            for (int i = 0; i < size; i++) {
                int[] cur = queue.poll();
                for (int[] d : dirs) {
                    int x = cur[0] + d[0];
                    int y = cur[1] + d[1];

                    if (x >= 0 && x < m && y >= 0 && y < n && grid[x][y] == 1) {
                        grid[x][y] = 2;
                        freshCount--;
                        queue.offer(new int[]{x, y});
                        hasRot = true;
                    }
                }
            }

            // 只有当这一分钟真的腐烂了橘子，才计时
            if (hasRot) {
                minutes++;
            }
        }

        // 3. 判断是否还有新鲜橘子
        return freshCount == 0 ? minutes : -1;
    }
}
```

---

## 💡 核心思路总结

- **多源 BFS**：所有初始腐烂橘子同时入队
    
- 每一层 BFS 表示 **1 分钟**
    
- 使用队列同步扩散
    
- 最终检查是否还有新鲜橘子

## 🔍 易错点提醒

- ✅ 初始就没有新鲜橘子 → 返回 `0`
    
- ✅ 必须判断 **是否真的在这一分钟腐烂了橘子**
    
- ✅ 最终要检查 `freshCount == 0`
