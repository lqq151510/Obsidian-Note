

**问题描述**：给定一个整数数组 `nums`，将数组中的元素**向右轮转**​ `k`个位置，其中 `k`是非负数。要求**原地修改数组**（空间复杂度 O(1)）。

**示例**：

输入：`nums = [1,2,3,4,5,6,7]`, `k = 3`

输出：`[5,6,7,1,2,3,4]`

---

### 带注释的代码实现

```
/**
 * 189. 轮转数组（Rotate Array）
 * 核心思路：三次反转法（原地操作，空间复杂度O(1)）
 */
class Solution {
    /**
     * 向右轮转数组 k 个位置的主方法
     * @param nums 待轮转的整数数组
     * @param k 轮转的位置数（非负数）
     */
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        // 处理 k 大于数组长度的情况：轮转 n 次等价于未轮转，取模简化计算
        k %= n;
        
        // 第一步：反转整个数组（将原数组的顺序完全颠倒）
        reverse(nums, 0, n - 1);
        // 第二步：反转前 k 个元素（原数组的后 k 个元素，反转后移动到数组前部）
        reverse(nums, 0, k - 1);
        // 第三步：反转剩余元素（原数组的前 n-k 个元素，反转后移动到数组后部）
        reverse(nums, k, n - 1);
    }
    
    /**
     * 辅助方法：反转数组中指定区间的元素
     * @param nums 目标数组
     * @param start 反转区间的起始索引（包含）
     * @param end 反转区间的结束索引（包含）
     */
    private void reverse(int[] nums, int start, int end) {
        // 双指针从区间两端向中间遍历，交换对应元素完成反转
        while (start < end) {
            int temp = nums[start];
            nums[start] = nums[end];
            nums[end] = temp;
            start++;
            end--;
        }
    }
}
```

---

### 代码原理演示（以 `nums = [1,2,3,4,5,6,7]`, `k=3`为例）

|步骤|操作|数组状态|
|---|---|---|
|初始|原数组|`[1,2,3,4,5,6,7]`|
|第一步|反转整个数组|`[7,6,5,4,3,2,1]`|
|第二步|反转前 `k=3`个元素|`[5,6,7,4,3,2,1]`|
|第三步|反转剩余 `n-k=4`个元素|`[5,6,7,1,2,3,4]`|

该方法通过三次反转实现了原地轮转，避免了额外空间的使用，时间复杂度为 O(n)。
