## 一、题目描述

**题目：300. 最长递增子序列（Longest Increasing Subsequence）**​

**难度：中等**

给你一个整数数组 `nums`，找到其中 **最长严格递增子序列**​ 的长度。

**子序列**​ 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]`是数组 `[0,3,1,6,2,2,7]`的子序列。

---

## 二、示例

|输入|输出|说明|
|---|---|---|
|`nums = [10,9,2,5,3,7,101,18]`|`4`|最长递增子序列是 `[2,3,7,101]`|
|`nums = [0,1,0,3,2,3]`|`4`|最长递增子序列是 `[0,1,2,3]`|
|`nums = [7,7,7,7,7,7,7]`|`1`|严格递增，所有元素相同，长度为 1|

---

## 三、解题思路（贪心 + 二分查找 ✅）

### 核心思想

维护一个数组 `tails`，其中：

- `tails[i]`表示 **长度为 `i+1`的递增子序列的最小可能末尾元素**
    

遍历数组 `nums`，对于每个元素 `x`：

- 在 `tails`中使用 **二分查找**​ 找到第一个 **大于等于 `x`**​ 的位置
    
- 用 `x`替换该位置的值（保持 `tails`严格递增）
    
- 如果 `x`大于 `tails`中所有元素，则追加到末尾
    

最终 `tails`的长度即为最长递增子序列的长度。

✅ **严格递增**：使用 `<`判断，确保不会接受相等元素

✅ **时间复杂度 O(n log n)**，**空间复杂度 O(n)**

## 四、Java 代码实现（你给出的版本 ✅）

```
class Solution {
    public int lengthOfLIS(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }

        int n = nums.length;
        int[] tails = new int[n]; // 存储各长度下的最小末尾
        int size = 0;             // 当前最长递增子序列长度

        for (int x : nums) {
            int left = 0, right = size;

            // 二分查找：找到第一个 >= x 的位置
            while (left < right) {
                int mid = left + (right - left) / 2;
                if (tails[mid] < x) {
                    left = mid + 1;
                } else {
                    right = mid;
                }
            }

            // 用 x 替换该位置的值
            tails[left] = x;

            // 如果 x 大于所有 tails 元素，则扩展长度
            if (left == size) {
                size++;
            }
        }

        return size;
    }
}
```

## 七、面试要点 ✅

- ✅ **首选解法**：贪心 + 二分查找（优于 DP）
    
- ✅ `tails`数组不表示真实 LIS，但长度等于 LIS 长度
    
- ✅ 二分查找条件是 `tails[mid] < x`（保证严格递增）
    
- ✅ `size`只在 `x`大于所有已有末尾时才增长
    

---

## 八、常见错误 ❌

|错误|说明|
|---|---|
|使用 `<=`作为二分条件|会破坏严格递增|
|误以为 `tails`就是 LIS|`tails`只是辅助数组|
|忽略空数组判断|会导致数组越界|

## 九、对比：动态规划解法（O(n²)）

```
// 仅作对比，面试不推荐
int n = nums.length;
int[] dp = new int[n];
int ans = 0;
for (int i = 0; i < n; i++) {
    dp[i] = 1;
    for (int j = 0; j < i; j++) {
        if (nums[j] < nums[i]) {
            dp[i] = Math.max(dp[i], dp[j] + 1);
        }
    }
    ans = Math.max(ans, dp[i]);
}
return ans;
```
