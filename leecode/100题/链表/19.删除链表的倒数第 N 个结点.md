
**描述**：给定一个链表，删除链表的倒数第 `n`个结点，并返回链表的头结点。

**示例**：

- 输入：`head = [1,2,3,4,5]`, `n = 2`
    
- 输出：`[1,2,3,5]`
    
    **关键点**：
    
- 链表长度至少为 `n`，保证删除有效。
    
- 需要一次遍历完成，避免多次扫描。
    

---

### 代码总结

```
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        // 1. 创建哑节点，指向头节点（处理删除头节点的边界情况）
        ListNode dummy = new ListNode(0, head);
        // 2. 定义快慢指针，初始都指向哑节点
        ListNode slow = dummy;
        ListNode fast = dummy;

        // 3. 快指针先走 n 步
        for (int i = 0; i < n; i++) {
            fast = fast.next;
        }

        // 4. 快慢指针同时走，直到快指针到达最后一个节点
        while (fast.next != null) {
            slow = slow.next;
            fast = fast.next;
        }

        // 5. 删除倒数第 n 个节点（慢指针的下一个节点）
        slow.next = slow.next.next;

        // 6. 返回新的头节点（哑节点的下一个）
        return dummy.next;
    }
}
```

#### 算法思路

- **双指针技巧**：
    
    - 使用哑节点简化边界处理（如删除头节点）。
        
    - 快指针先前进 `n`步，使得快慢指针之间相隔 `n`个结点。
        
    - 然后快慢指针同步前进，当快指针到达链表末尾时，慢指针恰好指向倒数第 `n`个结点的前驱。
        
    
- **时间复杂度**：O(L)，其中 L 是链表长度，仅需一次遍历。
    
- **空间复杂度**：O(1)，只使用常数额外空间。
    

#### 步骤详解

1. **哑节点**：`dummy.next = head`，避免单独处理头节点删除。
    
2. **快指针先行**：移动 `n`步，建立间隔。
    
3. **同步移动**：快慢指针同时前进，直到快指针的 `next`为 `null`。
    
4. **删除操作**：`slow.next = slow.next.next`跳过目标结点。
    
5. **返回结果**：`dummy.next`即为新头结点。
    

该方法高效且简洁，是链表问题中经典的“快慢指针”应用。
