# open-notebook

## Goal
Turn scattered findings into decision-ready notes.

## Workflow
1. Define question and success criteria.
2. Collect evidence with source reliability labels.
3. Compare options with tradeoffs.
4. Produce concise recommendations with assumptions.

## Output format
- Question
- Evidence table
- Recommendation
- Assumptions
