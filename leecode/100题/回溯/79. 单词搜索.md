
## 79. 单词搜索（Word Search）

### 📌 题目描述

给定一个 `m x n`的二维字符网格 `board`和一个字符串 `word`，

判断 `word`是否存在于网格中。

**规则：**

- 单词必须由**相邻单元格**（上下左右）的字母组成
    
- **同一个单元格不能被重复使用**
    
- 字母区分大小写
    

**示例：**

```
输入：
board = [
  ["A","B","C","E"],
  ["S","F","C","S"],
  ["A","D","E","E"]
]
word = "ABCCED"

输出：true
```

---

### 💡 解题思路（回溯 + DFS）

这是一个典型的 **回溯 / DFS 搜索问题**：

✅ 从每一个格子作为起点尝试

✅ 每次向 **上、下、左、右**​ 四个方向搜索

✅ 使用一个 `visited`数组防止重复使用

✅ 一旦匹配失败就回溯

---

### ✅ Java 实现（推荐写法）

```
class Solution {
    private char[][] board;
    private String word;
    private boolean[][] visited;
    private int m, n;

    public boolean exist(char[][] board, String word) {
        this.board = board;
        this.word = word;
        this.m = board.length;
        this.n = board[0].length;
        this.visited = new boolean[m][n];

        // 从每一个单元格开始尝试
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (dfs(i, j, 0)) {
                    return true;
                }
            }
        }
        return false;
    }

    private boolean dfs(int i, int j, int index) {
        // 如果已经匹配完整个单词
        if (index == word.length()) {
            return true;
        }

        // 越界、已访问、字符不匹配
        if (i < 0 || i >= m || j < 0 || j >= n ||
            visited[i][j] || board[i][j] != word.charAt(index)) {
            return false;
        }

        // 标记访问
        visited[i][j] = true;

        // 向四个方向搜索
        boolean found = dfs(i + 1, j, index + 1)
                    || dfs(i - 1, j, index + 1)
                    || dfs(i, j + 1, index + 1)
                    || dfs(i, j - 1, index + 1);

        // 回溯
        visited[i][j] = false;
        return found;
    }
}
```

---

### ⏱️ 复杂度分析

|项目|复杂度|
|---|---|
|时间复杂度|**O(m × n × 4^L)**（L 为 word 长度）|
|空间复杂度|**O(m × n)**（visited + 递归栈）|

---

### ✅ 常见优化点

- 可不用 `visited`数组，改为 **临时修改字符**（如 `'#'`）
    
- 若 `word`首字母出现次数很少，可先统计剪枝
    
- 实际面试中常问：**为什么必须回溯？**
