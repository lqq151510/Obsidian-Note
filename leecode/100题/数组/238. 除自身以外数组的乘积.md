

**问题描述**：

给定长度为 `n`的整数数组 `nums`，返回一个数组 `answer`，其中 `answer[i]`等于 `nums`中除 `nums[i]`之外其余各元素的乘积。

**要求**：

- **不能使用除法**。
    
- 时间复杂度为 **O(n)**。
    
- 题目数据保证数组 `nums`中任意元素的前缀和后缀乘积均在 32 位整数范围内。
    

**示例**：

```
输入：nums = [1,2,3,4]
输出：[24,12,8,6]

输入：nums = [-1,1,0,-3,3]
输出：[0,0,9,0,0]
```

---

### 解题思路：左右乘积法（两次遍历，空间优化）

1. **左侧乘积**：从左到右遍历，计算每个元素左侧所有元素的乘积，并暂存到结果数组中。
    
2. **右侧乘积**：从右到左遍历，维护一个变量 `R`表示当前元素右侧所有元素的乘积，同时将左侧乘积与右侧乘积相乘得到最终结果。
    

该方法仅需两次遍历，且无需额外数组存储右侧乘积，空间复杂度为 O(1)（不计输出数组）。

---

### 带详细注释的代码实现

```
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];

        // ---------- 第一步：计算左侧乘积 ----------
        // ans[i] 表示 nums[i] 左侧所有元素的乘积
        ans[0] = 1; // 第一个元素左侧没有元素，乘积为 1
        for (int i = 1; i < n; i++) {
            // 当前元素的左侧乘积 = 上一个元素的左侧乘积 × 上一个元素的值
            ans[i] = ans[i - 1] * nums[i - 1];
        }

        // ---------- 第二步：计算右侧乘积并与左侧乘积相乘 ----------
        int R = 1; // R 表示当前元素右侧所有元素的乘积，初始为 1（最右侧元素右边无元素）
        for (int i = n - 1; i >= 0; i--) {
            // 对于索引 i，其最终乘积 = 左侧乘积 ans[i] × 右侧乘积 R
            ans[i] = ans[i] * R;
            // 更新右侧乘积 R，乘以当前元素，供下一个（左边的）位置使用
            R *= nums[i];
        }

        return ans;
    }
}
```

---

### 执行过程演示（以 `nums = [1,2,3,4]`为例）

|步骤|操作|数组状态|
|---|---|---|
|初始化|`ans = [1, ?, ?, ?]`||
|左侧遍历|`i=1`: `ans[1] = 1 * 1 = 1`  <br>`i=2`: `ans[2] = 1 * 2 = 2`  <br>`i=3`: `ans[3] = 2 * 3 = 6`|`ans = [1, 1, 2, 6]`|
|右侧遍历|`i=3`: `R=1`, `ans[3]=6 * 1=6`, `R=4`  <br>`i=2`: `ans[2]=2 * 4=8`, `R=12`  <br>`i=1`: `ans[1]=1 * 12=12`, `R=24`  <br>`i=0`: `ans[0]=1 * 24=24`, `R=24`|`ans = [24, 12, 8, 6]`|

最终输出 `[24, 12, 8, 6]`，符合要求。
