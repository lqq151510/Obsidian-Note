## 一、题目描述

**题目：138. 随机链表的复制（Copy List with Random Pointer）**​

**难度：中等**

给你一个长度为 `n`的链表，每个节点除了 `next`指针外，还包含一个 **随机指针 `random`**，它可以指向链表中的任意节点或 `null`。

请你构造该链表的 **深拷贝**，并返回拷贝链表的头节点。

### 要求

- 拷贝链表中的节点必须是 **全新的节点**
    
- 新节点的 `next`和 `random`指针必须指向 **拷贝链表中的节点**
    
- **不能指向原链表中的任何节点**
    
- 原链表和拷贝链表完全独立
    

---

## 二、节点定义

```
class Node {
    int val;
    Node next;
    Node random;

    public Node(int val) {
        this.val = val;
        this.next = null;
        this.random = null;
    }
}
```

---

## 三、示例

```
输入：head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
输出：[[7,null],[13,0],[11,4],[10,2],[1,0]]
```

---

## 四、解题思路（哈希表法 ✅）

### 核心思想

1. **第一次遍历**：
    
    创建每一个新节点，并用 `HashMap<原节点, 新节点>`建立映射关系
    
2. **第二次遍历**：
    
    根据映射关系，设置新节点的 `next`和 `random`指针
    

✅ 时间复杂度：`O(n)`

✅ 空间复杂度：`O(n)`

---

## 五、Java 代码实现（哈希表版 ✅）

```
class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) {
            return null;
        }

        Map<Node, Node> map = new HashMap<>();

        // 1. 复制所有节点，建立原节点 -> 新节点映射
        Node cur = head;
        while (cur != null) {
            map.put(cur, new Node(cur.val));
            cur = cur.next;
        }

        // 2. 设置新节点的 next 和 random 指针
        cur = head;
        while (cur != null) {
            Node newNode = map.get(cur);
            newNode.next = map.get(cur.next);
            newNode.random = map.get(cur.random);
            cur = cur.next;
        }

        return map.get(head);
    }
}
```

## 六、进阶解法（O(1) 额外空间 ✅）

如果你在面试中被问到 **“能否不用哈希表？”**，可以使用 **原地复制法**：

### 核心步骤

1. 在每个原节点后插入一个新节点
    
2. 设置新节点的 `random`指针
    
3. 拆分链表，恢复原链表并取出新链表
    

### 示意图

```
原链表：A → B → C
插入后：A → A' → B → B' → C → C'
```

---

## 七、Java 代码（O(1) 空间解法）

```
class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) return null;

        // 1. 在原节点后插入复制节点
        Node cur = head;
        while (cur != null) {
            Node copy = new Node(cur.val);
            copy.next = cur.next;
            cur.next = copy;
            cur = copy.next;
        }

        // 2. 设置复制节点的 random 指针
        cur = head;
        while (cur != null) {
            if (cur.random != null) {
                cur.next.random = cur.random.next;
            }
            cur = cur.next.next;
        }

        // 3. 拆分链表
        cur = head;
        Node newHead = head.next;
        while (cur != null) {
            Node copy = cur.next;
            cur.next = copy.next;
            if (copy.next != null) {
                copy.next = copy.next.next;
            }
            cur = cur.next;
        }

        return newHead;
    }
}
```

## 八、复杂度对比

|解法|时间复杂度|空间复杂度|
|---|---|---|
|哈希表法|O(n)|O(n)|
|原地复制法|O(n)|O(1)|
