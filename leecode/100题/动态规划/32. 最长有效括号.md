## 一、题目描述

**题目：32. 最长有效括号（Longest Valid Parentheses）**​

**难度：困难**

给你一个只包含 `'('`和 `')'`的字符串，找出**最长有效（格式正确且连续）括号子串**的长度。

**有效括号**的定义：每个左括号 `'('`都有对应的右括号 `')'`将其闭合，且括号必须正确嵌套并连续。

---

## 二、示例

|输入|输出|说明|
|---|---|---|
|`"()(()"`|`2`|最长有效子串是 `"()"`|
|`")()())"`|`4`|最长有效子串是 `"()()"`|
|`""`|`0`|空字符串无有效括号|
|`"()(())"`|`6`|整个字符串都是有效的|

---

## 三、解题思路（动态规划 ✅）

### 核心思想

使用动态规划记录以每个位置结尾的最长有效括号长度。

### 状态定义

- `dp[i]`：表示以字符串第 `i`个字符（索引从 0 开始）结尾的最长有效括号长度
    

### 状态转移

1. **如果 `s.charAt(i) == ')'`：**
    
    - **情况 1**：`s.charAt(i-1) == '('`
        
        - 则 `dp[i] = dp[i-2] + 2`
            
        
    - **情况 2**：`s.charAt(i-1) == ')'`且 `s.charAt(i - dp[i-1] - 1) == '('`
        
        - 则 `dp[i] = dp[i-1] + 2 + dp[i - dp[i-1] - 2]`
            
        
    

### 初始化

- `dp[0] = 0`（单个字符不可能是有效括号）
    

### 最终结果

- 返回 `dp`数组中的最大值

## 四、Java 代码实现（推荐 ✅）

```
class Solution {
    public int longestValidParentheses(String s) {
        if (s == null || s.length() < 2) {
            return 0;
        }

        int n = s.length();
        int[] dp = new int[n]; // dp[i] 表示以 i 结尾的最长有效括号长度
        int maxLen = 0;

        for (int i = 1; i < n; i++) {
            if (s.charAt(i) == ')') {
                // 情况1：当前是 ')'，前一个是 '('
                if (s.charAt(i - 1) == '(') {
                    dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
                }
                // 情况2：当前是 ')'，前一个是 ')'，且前面有匹配的左括号
                else if (i - dp[i - 1] > 0 && s.charAt(i - dp[i - 1] - 1) == '(') {
                    int before = (i - dp[i - 1] >= 2) ? dp[i - dp[i - 1] - 2] : 0;
                    dp[i] = dp[i - 1] + 2 + before;
                }
                maxLen = Math.max(maxLen, dp[i]);
            }
        }

        return maxLen;
    }
}
```

## 六、执行过程示例

以 `s = ")()())"`为例：

|i|s[i]|dp[i]|说明|
|---|---|---|---|
|0|`)`|0|单个右括号无效|
|1|`(`|0|单个左括号无效|
|2|`)`|2|`"()"`匹配成功|
|3|`(`|0|单个左括号无效|
|4|`)`|4|`"()()"`匹配成功|
|5|`)`|0|无匹配的左括号|

## 七、面试要点 ✅

- ✅ 动态规划是解决此类问题的经典方法
    
- ✅ 重点处理两种匹配情况
    
- ✅ 注意边界条件（`i-2`、`i-dp[i-1]-2`的合法性）
    
- ✅ 时间复杂度 O(n)，空间复杂度 O(n)
    

---

## 八、常见错误 ❌

|错误|说明|
|---|---|
|只统计左右括号数量|无法处理 `")("`这种情况|
|忽略连续性的要求|需要连续的有效括号|
|未处理边界索引|容易导致数组越界|

## 九、其他方法简介

### 1. 栈方法（O(n) 时间，O(n) 空间）

- 使用栈存储索引，遇到 `'('`入栈，遇到 `')'`出栈并计算长度
    

### 2. 双指针法（O(n) 时间，O(1) 空间）

- 从左到右和从右到左各扫描一次，统计左右括号数量
