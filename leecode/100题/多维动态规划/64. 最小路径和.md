## 一、题目描述

**题目：64. 最小路径和（Minimum Path Sum）**​

**难度：中等**

给定一个包含非负整数的 `m x n`网格 `grid`，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

**说明：**​ 每次只能向下或者向右移动一步。

---

## 二、示例

|输入|输出|说明|
|---|---|---|
|`grid = [[1,3,1],[1,5,1],[4,2,1]]`|`7`|路径 `1→3→1→1→1`总和为 7|
|`grid = [[1,2,3],[4,5,6]]`|`12`|路径 `1→2→3→6`或 `1→4→5→6`总和为 12|
|`grid = [[5]]`|`5`|只有一个格子|

---

## 三、解题思路（动态规划 ✅）

### 核心思想

机器人只能向下或向右移动，因此到达任意格子 `(i,j)`的最小路径和等于：

- 从上方格子 `(i-1,j)`下来的最小路径和
    
- 与从左方格子 `(i,j-1)`过来的最小路径和
    
- 两者中的较小值，再加上当前格子的值
    

### 动态规划定义

- `dp[i][j]`：表示从起点 `(0,0)`到格子 `(i,j)`的最小路径和
    

### 状态转移方程

```
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

### 初始化

- `dp[0][0] = grid[0][0]`
    
- 第一行：`dp[0][j] = dp[0][j-1] + grid[0][j]`
    
- 第一列：`dp[i][0] = dp[i-1][0] + grid[i][0]`
    

### 最终结果

- `dp[m-1][n-1]`即为答案

## 四、Java 代码实现（推荐 ✅）

### 1. 二维动态规划（直观易懂）

```
class Solution {
    public int minPathSum(int[][] grid) {
        if (grid == null || grid.length == 0 || grid[0].length == 0) {
            return 0;
        }
        
        int m = grid.length;
        int n = grid[0].length;
        int[][] dp = new int[m][n];
        
        // 初始化起点
        dp[0][0] = grid[0][0];
        
        // 初始化第一行
        for (int j = 1; j < n; j++) {
            dp[0][j] = dp[0][j-1] + grid[0][j];
        }
        
        // 初始化第一列
        for (int i = 1; i < m; i++) {
            dp[i][0] = dp[i-1][0] + grid[i][0];
        }
        
        // 填充 dp 数组
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = Math.min(dp[i-1][j], dp[i][j-1]) + grid[i][j];
            }
        }
        
        return dp[m-1][n-1];
    }
}
```

### 2. 原地动态规划（空间优化 ✅）

```
class Solution {
    public int minPathSum(int[][] grid) {
        if (grid == null || grid.length == 0 || grid[0].length == 0) {
            return 0;
        }
        
        int m = grid.length;
        int n = grid[0].length;
        
        // 直接在原数组上修改，节省空间
        // 初始化第一行
        for (int j = 1; j < n; j++) {
            grid[0][j] += grid[0][j-1];
        }
        
        // 初始化第一列
        for (int i = 1; i < m; i++) {
            grid[i][0] += grid[i-1][0];
        }
        
        // 填充剩余格子
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                grid[i][j] += Math.min(grid[i-1][j], grid[i][j-1]);
            }
        }
        
        return grid[m-1][n-1];
    }
}
```

### 3. 一维动态规划（进一步优化）

```
class Solution {
    public int minPathSum(int[][] grid) {
        if (grid == null || grid.length == 0 || grid[0].length == 0) {
            return 0;
        }
        
        int m = grid.length;
        int n = grid[0].length;
        int[] dp = new int[n];
        
        // 初始化第一行
        dp[0] = grid[0][0];
        for (int j = 1; j < n; j++) {
            dp[j] = dp[j-1] + grid[0][j];
        }
        
        // 更新每一行
        for (int i = 1; i < m; i++) {
            // 更新第一列
            dp[0] += grid[i][0];
            // 更新其他列
            for (int j = 1; j < n; j++) {
                dp[j] = Math.min(dp[j], dp[j-1]) + grid[i][j];
            }
        }
        
        return dp[n-1];
    }
}
```

## 五、复杂度分析

|解法|时间复杂度|空间复杂度|
|---|---|---|
|二维 DP|O(m×n)|O(m×n)|
|原地 DP|O(m×n)|O(1)（除原数组外）|
|一维 DP|O(m×n)|O(n)|

## 六、执行过程示例

以 `grid = [[1,3,1],[1,5,1],[4,2,1]]`为例：

|步骤|说明|
|---|---|
|初始化 `dp[0][0] = 1`|起点|
|第一行：`dp[0][1]=4`, `dp[0][2]=5`|只能向右|
|第一列：`dp[1][0]=2`, `dp[2][0]=6`|只能向下|
|`dp[1][1] = min(4,2)+5 = 7`|取上或左的最小值|
|`dp[1][2] = min(5,7)+1 = 6`|...|
|`dp[2][1] = min(6,7)+2 = 8`|...|
|`dp[2][2] = min(6,8)+1 = 7`|最终结果|

✅ 最小路径和为 `7`

## 七、面试要点 ✅

- ✅ 明确只能向下或向右移动
    
- ✅ 动态规划状态转移方程是核心
    
- ✅ 原地修改可节省空间（面试加分）
    
- ✅ 注意边界条件（单行或单列网格）
    

---

## 八、常见错误 ❌

|错误|说明|
|---|---|
|使用贪心算法|局部最优不一定全局最优|
|忽略初始化|第一行/列未正确计算|
|混淆行列顺序|`m`是行数，`n`是列数|
