## 一、题目描述

**题目：139. 单词拆分（Word Break）**​

**难度：中等**

给你一个字符串 `s`和一个字符串列表 `wordDict`作为字典。如果可以利用字典中出现的一个或多个单词拼接出 `s`，则返回 `true`。

**注意：**

- 不要求字典中出现的单词全部使用
    
- 字典中的单词可以重复使用
    

---

## 二、示例

|输入|输出|说明|
|---|---|---|
|`s = "leetcode", wordDict = ["leet","code"]`|`true`|`"leet" + "code"`拼接成 `"leetcode"`|
|`s = "applepenapple", wordDict = ["apple","pen"]`|`true`|`"apple" + "pen" + "apple"`|
|`s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]`|`false`|无法拼接成 `"catsandog"`|

---

## 三、解题思路（动态规划 ✅）

### 核心思想

这是一个典型的 **动态规划**​ 问题，通过判断子串是否能被拆分来推导整体结果。

### 状态定义

- `dp[i]`：表示字符串 `s`的 **前 `i`个字符**​ 是否可以被拆分成字典中的单词
    

### 状态转移方程

对于每个位置 `i`（`1 ≤ i ≤ s.length()`）：

- 枚举所有可能的 `j`（`0 ≤ j < i`）
    
- 如果 `dp[j]`为 `true`，且子串 `s[j..i-1]`存在于字典中，则 `dp[i] = true`
    

### 初始化

- `dp[0] = true`：空字符串可以被拆分成 0 个单词
    

### 最终结果

- `dp[s.length()]`：表示整个字符串是否可以被拆分
    

---

## 四、Java 代码实现（推荐 ✅）

```
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        // 将字典转换为 HashSet，提高查找效率
        Set<String> wordSet = new HashSet<>(wordDict);
        int n = s.length();

        // dp[i] 表示前 i 个字符是否可以被拆分
        boolean[] dp = new boolean[n + 1];
        dp[0] = true; // 空字符串可以被拆分

        // 遍历字符串的每个位置
        for (int i = 1; i <= n; i++) {
            // 检查所有可能的拆分点 j
            for (int j = 0; j < i; j++) {
                // 如果前 j 个字符可以被拆分，且子串 s[j..i-1] 在字典中
                if (dp[j] && wordSet.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break; // 找到一个有效拆分即可
                }
            }
        }

        return dp[n];
    }
}
```

## 五、复杂度分析

|指标|结果|
|---|---|
|时间复杂度|**O(n²)**（n 为字符串长度，双重循环）|
|空间复杂度|**O(n + m)**（n 为字符串长度，m 为字典单词总数）|

---

## 六、执行过程示例

以 `s = "leetcode", wordDict = ["leet","code"]`为例：

1. `dp[0] = true`
    
2. `i=4`：检查 `j=0`，`s[0..3] = "leet"`在字典中 → `dp[4] = true`
    
3. `i=8`：检查 `j=4`，`s[4..7] = "code"`在字典中 → `dp[8] = true`
    
4. 返回 `dp[8] = true`
    

---

## 七、面试要点 ✅

- ✅ 使用 **动态规划**​ 解决子问题重叠的问题
    
- ✅ 将字典转为 `HashSet`，避免重复查找
    
- ✅ 初始化 `dp[0] = true`是关键
    
- ✅ 枚举拆分点时，找到第一个有效拆分即可提前退出
    

---

## 八、常见错误 ❌

|错误|说明|
|---|---|
|未处理空字符串|`dp[0] = true`必须初始化|
|使用 `List`直接查找|会导致 O(k) 的查找时间，降低效率|
|忽略子串长度|可优化为仅检查字典中单词的长度，减少枚举次数|
|未考虑单词重复使用|动态规划天然支持重复使用，无需额外处理|

---

## 九、优化思路（可选）

如果字典中单词长度差异较大，可以预先记录所有单词的长度，仅检查这些长度的 `j`，减少内层循环次数：

```
Set<Integer> wordLengths = new HashSet<>();
for (String word : wordDict) {
    wordLengths.add(word.length());
}
// 在内层循环中，仅检查 j = i - len（len ∈ wordLengths）
```
