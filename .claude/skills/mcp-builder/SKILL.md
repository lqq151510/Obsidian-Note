# mcp-builder

## Goal
Design production-ready MCP tools quickly.

## Workflow
1. Define tool contract (inputs, outputs, errors).
2. Implement handlers with validation and auth boundaries.
3. Add observability and retry-safe behavior.
4. Verify with end-to-end tool calls.

## Output format
- Tool schema
- Implementation notes
- Test cases
