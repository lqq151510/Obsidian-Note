

## 题目描述

编写一个高效的算法来搜索 `m x n`矩阵 `matrix`中的一个目标值 `target`。该矩阵具有以下特性：

- 每行的元素从左到右升序排列。
    
- 每列的元素从上到下升序排列。
    

## 解决方案代码（Java）

```
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            return false;
        }

        int m = matrix.length;
        int n = matrix[0].length;

        // 从右上角开始搜索
        int row = 0;
        int col = n - 1;

        while (row < m && col >= 0) {
            if (matrix[row][col] == target) {
                return true; // 找到目标
            } else if (matrix[row][col] > target) {
                col--; // 当前值太大，往左移排除一列
            } else {
                row++; // 当前值太小，往下移排除一行
            }
        }

        return false; // 越界未找到
    }
}
```

## 算法思路

1. **选择起始点**：从矩阵的**右上角**（或左下角）开始搜索。
    
2. **逐步缩小范围**：
    
    - 若当前值等于 `target`，返回 `true`。
        
    - 若当前值大于 `target`，则当前列所有值均大于 `target`，向左移动一列（`col--`）。
        
    - 若当前值小于 `target`，则当前行所有值均小于 `target`，向下移动一行（`row++`）。
        
    
3. **终止条件**：当指针越界仍未找到目标，返回 `false`。
    

## 复杂度分析

- **时间复杂度**：`O(m + n)`，每次循环排除一行或一列。
    
- **空间复杂度**：`O(1)`，仅使用常数额外空间。
