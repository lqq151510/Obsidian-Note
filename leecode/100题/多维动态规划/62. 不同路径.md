## 一、题目描述

**题目：62. 不同路径（Unique Paths）**​

**难度：中等**

一个机器人位于一个 `m x n`网格的左上角（起始点标记为 **“Start”**）。机器人每次只能 **向下**​ 或 **向右**​ 移动一步。机器人试图达到网格的右下角（标记为 **“Finish”**）。

问总共有多少条不同的路径？

---

## 二、示例

|输入|输出|说明|
|---|---|---|
|`m = 3, n = 7`|`28`|3行7列网格，共有28种路径|
|`m = 3, n = 2`|`3`|3行2列网格，共有3种路径|
|`m = 1, n = 1`|`1`|单个格子，只有1种路径|

---

## 三、解题思路（动态规划 ✅）

### 核心思想

机器人只能向下或向右移动，因此到达任意格子 `(i,j)`的路径数等于：

- 从上方格子 `(i-1,j)`下来的路径数
    
- 加上从左方格子 `(i,j-1)`过来的路径数
    

### 动态规划定义

- `dp[i][j]`：表示从起点 `(0,0)`到格子 `(i,j)`的不同路径数
    

### 状态转移方程

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

### 初始化

- 第一行 `dp[0][j] = 1`（只能一直向右）
    
- 第一列 `dp[i][0] = 1`（只能一直向下）
    

### 最终结果

- `dp[m-1][n-1]`即为答案
    

---

## 四、Java 代码实现（推荐 ✅）

### 1. 二维动态规划（直观易懂）

```
class Solution {
    public int uniquePaths(int m, int n) {
        if (m <= 0 || n <= 0) return 0;
        
        int[][] dp = new int[m][n];
        
        // 初始化第一行和第一列
        for (int i = 0; i < m; i++) dp[i][0] = 1;
        for (int j = 0; j < n; j++) dp[0][j] = 1;
        
        // 填充 dp 数组
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i-1][j] + dp[i][j-1];
            }
        }
        
        return dp[m-1][n-1];
    }
}
```

### 2. 一维动态规划（空间优化 ✅）

```
class Solution {
    public int uniquePaths(int m, int n) {
        if (m <= 0 || n <= 0) return 0;
        
        int[] dp = new int[n];
        // 初始化第一行：所有列都是1
        for (int j = 0; j < n; j++) dp[j] = 1;
        
        // 从第1行开始更新
        for (int i = 1; i < m; i++) {
            // 第0列始终是1（只能向下）
            for (int j = 1; j < n; j++) {
                dp[j] = dp[j] + dp[j-1]; // 上 + 左
            }
        }
        
        return dp[n-1];
    }
}
```

## 五、复杂度分析

|解法|时间复杂度|空间复杂度|
|---|---|---|
|二维 DP|O(m×n)|O(m×n)|
|一维 DP|O(m×n)|O(n)|

## 六、执行过程示例

以 `m = 3, n = 7`为例：

1. 初始化 `dp`数组第一行和第一列为 1
    
2. 填充 `dp[1][1] = dp[0][1] + dp[1][0] = 1 + 1 = 2`
    
3. 依次计算所有格子，最终 `dp[2][6] = 28`

## 七、面试要点 ✅

- ✅ 明确机器人只能向下或向右移动
    
- ✅ 动态规划状态转移方程是核心
    
- ✅ 一维优化更节省空间（面试加分）
    
- ✅ 注意边界条件（单行或单列网格）

## 八、常见错误 ❌

|错误|说明|
|---|---|
|使用递归（无记忆化）|时间复杂度指数级，会超时|
|忽略初始化|第一行/列未正确设置为1|
|混淆行列顺序|`m`是行数，`n`是列数|

## 九、数学解法（组合数公式）

机器人总共需要移动 `(m-1)`次向下和 `(n-1)`次向右，总步数为 `(m+n-2)`步。问题等价于从 `(m+n-2)`步中选择 `(m-1)`步向下（或 `(n-1)`步向右）。

公式：

```
C(m+n-2, m-1) = (m+n-2)! / [(m-1)! × (n-1)!]
```

代码示例：

```
class Solution {
    public int uniquePaths(int m, int n) {
        long res = 1;
        // 计算组合数 C(m+n-2, m-1)
        for (int i = 1; i <= m-1; i++) {
            res = res * (n - 1 + i) / i;
        }
        return (int) res;
    }
}
```
