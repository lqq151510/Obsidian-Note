## 一、题目描述

**题目：25. K 个一组翻转链表（Reverse Nodes in k-Group）**​

**难度：困难**

给你链表的头节点 `head`，每 `k`个节点一组进行翻转，请你返回修改后的链表。

### 要求

- `k`是一个正整数，且 `k ≤ 链表长度`
    
- 如果节点总数不是 `k`的整数倍，**最后剩余的节点保持原有顺序**
    
- **不能只修改节点的值，必须实际交换节点**
    

---

## 二、示例

|输入|k|输出|
|---|---|---|
|`1 → 2 → 3 → 4 → 5`|2|`2 → 1 → 4 → 3 → 5`|
|`1 → 2 → 3 → 4 → 5`|3|`3 → 2 → 1 → 4 → 5`|
|`1 → 2 → 3 → 4`|2|`2 → 1 → 4 → 3`|

---

## 三、解题思路

1. 使用 **虚拟头节点（dummy）**，简化头节点变化的处理
    
2. 每次截取 `k`个节点作为一组
    
3. 若不足 `k`个，直接结束
    
4. 对每组执行 **区间反转**
    
5. 将反转后的子链表重新接回原链表
    
6. 移动到下一组继续处理
    

✅ **时间复杂度 O(n)，空间复杂度 O(1)**

---

## 四、Java 代码实现（已整理）

```
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        if (head == null || k == 1) {
            return head;
        }

        // 虚拟头节点，统一处理边界情况
        ListNode dummy = new ListNode(0);
        dummy.next = head;

        // prev 始终指向下一组反转前的前驱节点
        ListNode prev = dummy;
        ListNode curr = head;

        while (curr != null) {
            // 1. 找到当前组的尾节点
            ListNode tail = prev;
            for (int i = 0; i < k; i++) {
                tail = tail.next;
                if (tail == null) {
                    return dummy.next;
                }
            }

            // 2. 保存下一组的起点
            ListNode nextGroupHead = tail.next;

            // 3. 反转当前组 [prev.next, tail]
            reverse(prev.next, tail);

            // 4. 重新连接链表
            prev.next = tail;
            curr.next = nextGroupHead;

            // 5. 移动指针到下一组
            prev = curr;
            curr = nextGroupHead;
        }

        return dummy.next;
    }

    /**
     * 反转链表区间 [start, end]
     */
    private void reverse(ListNode start, ListNode end) {
        ListNode prev = end.next;
        ListNode curr = start;

        while (prev != end) {
            ListNode next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }
    }
}
```
