
### 题目描述

给定一个仅包含数字 `'2'`–`'9'`的字符串 `digits`，返回该数字序列所能表示的所有字母组合。

答案可以按 **任意顺序**​ 返回。

### 数字到字母的映射（与电话按键一致）

```
2 -> abc
3 -> def
4 -> ghi
5 -> jkl
6 -> mno
7 -> pqrs
8 -> tuv
9 -> wxyz
```

> ⚠️ 数字 `1`不对应任何字母。

### 示例

|输入|输出|
|---|---|
|`"23"`|`["ad","ae","af","bd","be","bf","cd","ce","cf"]`|
|`""`|`[]`|
|`"2"`|`["a","b","c"]`|

### 约束条件

- `0 <= digits.length <= 4`
    
- `digits[i]`为 `'2'`到 `'9'`
    

---

## 解题思路（回溯 / Backtracking）

- 每个数字对应一组字母
    
- 使用 **回溯**​ 逐位构造字符串
    
- 当构造长度等于 `digits.length()`时，加入结果集
    
- 回溯时撤销上一次选择（删除最后一个字符）
    

---

## ✅ Java 实现（已整理 & 规范）

```
import java.util.ArrayList;
import java.util.List;

public class Solution {

    // 数字到字母的映射
    private static final String[] MAPPING = {
        "", "", "abc", "def", "ghi",
        "jkl", "mno", "pqrs", "tuv", "wxyz"
    };

    public List<String> letterCombinations(String digits) {
        List<String> result = new ArrayList<>();
        if (digits == null || digits.isEmpty()) {
            return result;
        }
        backtrack(digits, 0, new StringBuilder(), result);
        return result;
    }

    private void backtrack(String digits, int index, StringBuilder path, List<String> result) {
        // 终止条件
        if (index == digits.length()) {
            result.add(path.toString());
            return;
        }

        // 当前数字对应的字母
        String letters = MAPPING[digits.charAt(index) - '0'];
        for (int i = 0; i < letters.length(); i++) {
            path.append(letters.charAt(i));
            backtrack(digits, index + 1, path, result);
            path.deleteCharAt(path.length() - 1); // 回溯
        }
    }

    // 测试
    public static void main(String[] args) {
        Solution solution = new Solution();

        System.out.println("23  -> " + solution.letterCombinations("23"));
        System.out.println("\"\" -> " + solution.letterCombinations(""));
        System.out.println("2   -> " + solution.letterCombinations("2"));
        System.out.println("9   -> " + solution.letterCombinations("9"));
        System.out.println("79  -> " + solution.letterCombinations("79"));
    }
}
```

## 复杂度分析

|项目|说明|
|---|---|
|时间复杂度|**O(4ⁿ)**（`n`为 digits 长度，最多 4 个字母）|
|空间复杂度|**O(n)**（递归栈 + 当前路径）|
