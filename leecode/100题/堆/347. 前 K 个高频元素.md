## 一、题目描述

**题目：347. 前 K 个高频元素（Top K Frequent Elements）**

**难度：中等**

给你一个整数数组 `nums`和一个整数 `k`，请你返回其中出现频率前 `k`高的元素。你可以按 **任意顺序**​ 返回答案。

---

## 二、示例

|输入|输出|
|---|---|
|`nums = [1,1,1,2,2,3], k = 2`|`[1,2]`|
|`nums = [1], k = 1`|`[1]`|
|`nums = [4,1,4,4,5,5,5], k = 2`|`[4,5]`|

---

## 三、解题思路（哈希表 + 最小堆 ✅）

### 核心步骤

1. **统计频率**：使用哈希表记录每个元素的出现次数
    
2. **维护前 k 个高频元素**：使用大小为 `k`的最小堆
    
    - 堆中存储 `[元素, 频率]`
        
    - 当堆大小超过 `k`时，弹出频率最小的元素
        
    
3. **提取结果**：堆中剩余的元素即为前 `k`个高频元素
    

✅ 时间复杂度：**O(n log k)**​

✅ 空间复杂度：**O(n)**

---

## 四、Java 代码实现（推荐 ✅）

```
import java.util.*;

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        // 1. 统计每个元素的频率
        Map<Integer, Integer> freqMap = new HashMap<>();
        for (int num : nums) {
            freqMap.put(num, freqMap.getOrDefault(num, 0) + 1);
        }

        // 2. 使用最小堆（按频率排序）维护前 k 个高频元素
        PriorityQueue<int[]> minHeap = new PriorityQueue<>(
            (a, b) -> a[1] - b[1]  // 按频率升序排列（最小堆）
        );

        for (Map.Entry<Integer, Integer> entry : freqMap.entrySet()) {
            int num = entry.getKey();
            int freq = entry.getValue();
            minHeap.offer(new int[]{num, freq});

            // 堆大小超过 k 时，移除频率最小的元素
            if (minHeap.size() > k) {
                minHeap.poll();
            }
        }

        // 3. 提取结果
        int[] result = new int[k];
        for (int i = 0; i < k; i++) {
            result[i] = minHeap.poll()[0];
        }
        return result;
    }
}
```

## 五、进阶解法（桶排序 ✅）

如果要求 **O(n)**​ 时间复杂度，可以使用桶排序：

```
class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        // 1. 统计频率
        Map<Integer, Integer> freqMap = new HashMap<>();
        for (int num : nums) {
            freqMap.put(num, freqMap.getOrDefault(num, 0) + 1);
        }

        // 2. 创建桶，下标为频率，值为元素列表
        List<Integer>[] buckets = new List[nums.length + 1];
        for (Map.Entry<Integer, Integer> entry : freqMap.entrySet()) {
            int freq = entry.getValue();
            if (buckets[freq] == null) {
                buckets[freq] = new ArrayList<>();
            }
            buckets[freq].add(entry.getKey());
        }

        // 3. 从高到低收集前 k 个元素
        int[] result = new int[k];
        int index = 0;
        for (int i = buckets.length - 1; i >= 0 && index < k; i--) {
            if (buckets[i] != null) {
                for (int num : buckets[i]) {
                    result[index++] = num;
                    if (index == k) break;
                }
            }
        }
        return result;
    }
}
```

|解法|时间复杂度|空间复杂度|
|---|---|---|
|最小堆|O(n log k)|O(n)|
|桶排序|O(n)|O(n)|

## 七、面试要点 ✅

- ✅ 使用哈希表统计频率是基础
    
- ✅ **最小堆**​ 比最大堆更适合 Top K 问题（节省空间）
    
- ✅ 堆中存储 `[元素, 频率]`，比较器按频率排序
    
- ✅ 桶排序在频率范围较小时可达到线性时间复杂度
    
- ✅ 题目允许任意顺序返回结果
    

---

## 八、常见错误 ❌

|错误|说明|
|---|---|
|使用最大堆|会保留大量无用元素，浪费空间|
|忽略 k 的有效性|题目保证 `1 ≤ k ≤ 不同元素个数`|
|频率相同时的顺序问题|无需特殊处理，任意顺序均可|

## 九、执行流程示例

以 `nums = [1,1,1,2,2,3], k = 2`为例：

1. 频率统计：`{1:3, 2:2, 3:1}`
    
2. 最小堆变化：
    
    - 加入 `[1,3]`→ 堆：`[1,3]`
        
    - 加入 `[2,2]`→ 堆：`[2,2, 1,3]`
        
    - 加入 `[3,1]`→ 堆大小 > 2，弹出 `[3,1]`→ 堆：`[2,2, 1,3]`
        
    
3. 结果：`[2,1]`（或 `[1,2]`）
