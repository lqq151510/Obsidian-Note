
## 问题描述

给定一个整数数组 `nums`，有一个大小为 `k`的滑动窗口从数组最左侧移动到最右侧。你只能看到窗口内的 `k`个数字。窗口每次向右移动一位。

请返回**滑动窗口中的最大值**。

**示例：**

```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
解释：
窗口位置              最大值
---------------      -----
[1  3  -1] -3  5  3  6  7   → 3
 1 [3  -1  -3] 5  3  6  7   → 3
 1  3 [-1  -3  5] 3  6  7   → 5
 1  3  -1 [-3  5  3] 6  7   → 5
 1  3  -1  -3 [5  3  6] 7   → 6
 1  3  -1  -3  5 [3  6  7]  → 7
```

---

## 解题思路（单调队列）

使用**单调递减的双端队列**来维护窗口中的最大值：

- 队列中**存储下标**（便于判断元素是否滑出窗口）
    
- 队列头部始终是当前窗口最大值的下标
    
- 新元素入队前，移除所有比它小的元素（因为它们不可能再成为最大值）
    

---

## Java 代码实现

```
import java.util.*;

class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        if (nums == null || nums.length == 0 || k <= 0) {
            return new int[0];
        }

        int n = nums.length;
        int[] res = new int[n - k + 1];
        Deque<Integer> deque = new LinkedList<>(); // 存储下标，保证队头最大

        for (int i = 0; i < n; i++) {
            // 1. 移除窗口外的元素（队头下标过期）
            if (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
                deque.pollFirst();
            }

            // 2. 维护单调递减：移除所有比当前元素小的队尾元素
            while (!deque.isEmpty() && nums[deque.peekLast()] < nums[i]) {
                deque.pollLast();
            }

            // 3. 当前元素入队
            deque.offerLast(i);

            // 4. 当窗口形成后，记录最大值（队头）
            if (i >= k - 1) {
                res[i - k + 1] = nums[deque.peekFirst()];
            }
        }
        return res;
    }
}
```

## 算法流程示意

以 `nums = [1,3,-1,-3,5,3,6,7], k = 3`为例：

|i|nums[i]|队列（下标）|最大值|
|---|---|---|---|
|0|1|[0]|—|
|1|3|[1]|—|
|2|-1|[1,2]|3|
|3|-3|[1,2,3]|3|
|4|5|[4]|5|
|5|3|[4,5]|5|
|6|6|[6]|6|
|7|7|[7]|7|

---

## 复杂度分析

- **时间复杂度**：O(n)，每个元素最多入队、出队一次
    
- **空间复杂度**：O(k)，队列最多存储 k 个元素
